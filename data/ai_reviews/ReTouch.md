## 1. 한 줄 요약

ReTouch는 다섯 손가락 촉각 신호를 손가락별 패치 구조로 인코딩하고, **미래 촉각 예측을 액션 청크 실행 중에 계속 갱신되는 "제어 상태"로 취급**하는 VLA로, 실기 7개 접촉 집약 태스크에서 최강 베이스라인 대비 표준 조건 +18.4%p, 도전 조건 +23.8%p를 달성한다.

## 2. 문제 정의

접촉 집약형(contact-rich) 덱스터러스 조작은 어떤 손가락이 접촉 중인지, 물체가 미끄러지는지, 다지(multi-finger) 접촉이 안정적인지를 지속적으로 추적해야 한다. VLA는 지시 이해와 장면 수준 인지를 제공하지만, 시각만으로는 접촉 위치·힘·파지 안정성을 신뢰성 있게 파악할 수 없고, 다지 조작에서는 손-물체 가림(occlusion)이 접촉 영역 자체를 감춘다. 논문은 촉각 인지 정책 적용 시 두 가지 구체적 난점을 지적한다.

1. **표현 구조 소실**: 덱스터러스 핸드는 조밀한 촉각 관측(손가락당 120개 3축 택셀)을 만들지만, 태스크 관련 접촉은 특정 손가락·특정 지첨 영역에 희소하게 국지화된다. 기존 방식은 촉각을 일반 토큰으로 평탄화하거나 손가락별 시간 이력을 압축해, 손가락 단위 공간 구조가 사라진다.
2. **예측 노후화(staleness)**: 슬립·접촉 이동·실행 오차로 접촉 상태가 급변하면, 액션 청크 시작 시점에 생성된 미래 촉각 예측이 실행 도중 낡아버린다. 기존 predictive-reactive 방식조차 고속 촉각 피드백으로 **액션만** 수정하고, 그 액션을 인도하는 **촉각 예측 자체는 재추정하지 않는다**.

## 3. 핵심 아이디어

ReTouch는 위 두 문제에 각각 대응한다.

- **Tactile-Patch Encoder**: 손가락별 국지 접촉 위상(topology)을 보존하는 구조적 촉각 표현.
- **Online Tactile Prediction Refinement**: 미래 촉각 잠재를 재귀적으로 유지되는 제어 상태로 두고, 각 고주파 호출마다 최신 촉각 피드백으로 **예측과 남은 액션을 함께** 갱신.

핵심 문장: "촉각 예측은 고정된 예보(forecast)가 아니라 실행 피드백으로 갱신되는 제어 상태일 때 가장 효과적이다."

## 4. 방법 — Tactile-Patch Encoder

각 손가락의 120개 3D 힘 택셀을 기능적 접촉 영역에 따라 **tip / center / base / left / right** 5개 패치로 분할한다. 택셀-패치 매핑은 고정이며, 엄지는 T30 센서 맵, 나머지 네 손가락은 T16 맵을 공유한다.

힘 크기로부터 소프트 접촉 가중치를 계산한다:

```
w_j = sigmoid( (||f_j||_2 - theta_c) / gamma_c ),   W_p = sum_{j in I_p} w_j
```

패치 통계는 접촉 게이팅 평균력 `f̄_p = (sum w_j f_j) / max(W_p, eps)`, 성분별 최대 절대력 `m_p = max |f_j|`, 접촉 면적 `a_p = W_p / |I_p|`, 접촉 강도 `q_p = max ||f_j||_2` 네 가지다. 하이퍼파라미터는 인코더 사전학습 시 `theta_c = 0.5`, 정책 학습 시 `theta_c = 1.0`, `gamma_c = 0.5`, `eps = 1e-6`.

Patch-Informed Tokenizer가 이 국지 응답을 8→256→1024 SiLU MLP로 투영하고 **손가락 정체성(finger-identity) 임베딩 + 패치 위치 임베딩**을 더한 뒤, 학습된 스칼라 투영 `g`로 패치 간 소프트맥스 풀링을 수행해 손가락당 하나의 압축 토큰 `z`를 만든다:

```
e_p = g(SiLU(h_p)) + log(a_p + eps),   alpha_p = softmax(e_p),   z = LayerNorm( sum_p alpha_p h_p )
```

결과적으로 프레임당 **촉각 토큰 5개만** 정책에 노출하면서도 손가락별 접촉 위상을 유지한다. 인코더는 세 개의 예측 헤드(패치 간 접촉 강도 분포 — 교차 엔트로피, 패치별 접촉 게이팅 평균 3D 힘 복원 — 회귀, 접촉 상태 — BCE)로 20k step 사전학습된다:

```
L_TPE = lambda_dist * L_CE + lambda_force * L_force + lambda_contact * L_BCE
L_force = L_active + 0.5 * L_magnitude + 0.25 * L_inactive   (Smooth-L1)
```

사전학습 후 헤드는 폐기하고 가중치만 정책에 이식한다.

## 5. 방법 — Hindsight/Foresight 이중 액션 전문가

미래 택셀 수준 신호를 직접 복원하는 대신, **액션 생성에 관련된 촉각 정보만** 담은 잠재를 학습한다. 아키텍처적으로 동일하되 파라미터는 독립인 두 전문가를 쓴다.

- **HAE (Hindsight Action Expert)**: 학습 전용 특권(privileged) 분기. 실제 미래 촉각 신호 `tau_{t:t+H}`를 Tactile-Patch Encoder로 변환해 조건화하고, 액션 생성 목적으로 최적화되므로 그 내부 표현이 자연히 "액션 관련" 미래 촉각 정보가 된다. 정렬 층 `l`에서 이를 hindsight 타깃으로 추출.
- **FAE (Foresight Action Expert)**: 배포 가능한 경로. 학습 가능한 **Tactile Foresight Queries** `Q_fore`를 사용해, 캐시된 의미 컨텍스트 `c_k`, 청크 시작 로봇 상태 `s_k`, 관측 촉각 컨텍스트 `T_t`만으로 미래 촉각 잠재를 추론.

정렬 손실은 stop-gradient가 걸린 코사인 거리다:

```
L_align = d_cos( g_psi(Ẑ⁺_{t,l}),  sg(Z⁺,hid_{t,l}) )
```

HAE/FAE는 각각 **18층 Transformer, hidden 1024, 8 head**이며 정렬 층은 `l = 12`, 투영기는 1024→1024→1024 SiLU, 정렬 가중치 0.1. 배포 시 HAE와 투영기는 제거되고 FAE만 남는다.

전체 정책 목적:

```
L_policy = L_act^hid + L_act^fore + lambda_align * L_align + L_update
```

## 6. 방법 — 온라인 촉각 예측 갱신

ReTouch는 **다중 속도 비동기(multi-rate asynchronous)** 실행을 쓴다. VLM은 9 Hz로 시각·언어를 처리하고 의미 컨텍스트를 캐시하며, FAE는 36 Hz로 돌아 VLM 갱신 사이에 여러 번 호출된다.

초기 호출 이후에는 이전 호출의 잠재 접두부를 이어받아 쿼리를 구성한다:

```
Q̃_fore_t = M_t ⊙ sg(Ẑ⁺_{t-1}) + (1 - M_t) ⊙ Q_fore
(Ẑ⁺_t, Â_t) = FAE_theta( c_k, s_k, T_t, Q̃_fore_t )
```

`M_t`는 이미 경과한 액션 청크 부분에 해당하는 잠재 접두부를 선택하며, 최초 호출은 `M_t = 0`이다.

**방향성 어텐션 마스크**가 핵심 설계다. Tactile Foresight Queries는 의미 컨텍스트·로봇 상태·촉각 컨텍스트·이월된 잠재 접두부에는 어텐션할 수 있으나 **액션 토큰에는 접근할 수 없고**, 반대로 액션 토큰은 갱신된 미래 촉각 잠재에 어텐션한다. 따라서 매 호출에서 촉각 예측이 먼저 형성되고 그 위에서 액션 청크가 생성되며, 액션 토큰 정보가 촉각 잠재로 누출되지 않는다.

학습과 배포가 같은 스킴을 따르도록, 학습 시 청크 내 중간 오프셋을 `{4, 8, 12}`에서 무작위 샘플링해 그 상태로부터 잠재와 남은 액션을 갱신하도록 학습시킨다. 배포 시 매 호출은 16-step 청크 전체를 재생성하되 오프셋 이후 미실행 접미부 `Â^(o)_t[o:16]`만 적용한다.

액션은 flow matching으로 학습된다: `eps ~ N(0,I)`, `t = 0.001 + 0.999 * t̃` (`t̃ ~ Beta(1.5, 1)`), `x_t = t*eps + (1-t)*a`, `u = eps - a`를 MSE로 회귀. 추론은 `t = 1 → 0` 명시적 오일러 10 step이며, 같은 청크 내 모든 갱신 호출은 동일한 초기 액션 노이즈를 재사용한다.

## 7. XHT-Dataset 및 실험 설정

**플랫폼**: UR7e 암 + XHand 5지 덱스터러스 핸드, 손목 장착 RGB 1대 + 고정 외부 RGB 2대. 원격조작 시 VIVE 트래커가 손목 자세를, MANUS 글러브가 손가락 동작을 기록.

**데이터**: 7개 접촉 집약 태스크에 걸쳐 **900개 성공 시연**. 100개는 오프라인 홀드아웃 테스트셋(인코더 사전학습·정책 학습 모두에서 제외), 나머지 800개가 공통 학습 풀.

**태스크**: (1) Pipette Press — 피펫을 집어 버튼을 정밀 압박, (2) Bottle Grasp — 무게가 다른 투명 물병 파지, (3) Cob Grasp — 서로 다른 높이의 옥수수를 집기, (4) Sponge Wipe — 스펀지로 화이트보드 자국 닦기, (5) Button Press — 작은 버튼 누르기, (6) Cabinet Retrieval — 시각 가림 상태에서 서랍을 열고 투명 비커 회수·배치, (7) Liquid Transfer — 플라스틱 피펫으로 메스실린더에서 비커로 물 이송.

**지표**: 방법당 태스크별 실기 롤아웃 20회. 정규화 태스크 점수(%)를 보고하며, Button Press만 이진(표시등 점등 시 1.0)이고 나머지는 단계별 가중 부분 점수다. 예: Pipette Press는 파지 0.4 + 전체 스트로크 1/3~1/2 압박 0.3 + 1/2 이상 0.3. 타임아웃은 앞 다섯 태스크 60초, Liquid Transfer/Cabinet Retrieval 120초. **따라서 본문의 "success rate"는 이진 성공 빈도가 아니라 등급화된 태스크 완수 점수의 평균**이라는 점에 유의해야 한다.

**학습 자원**: A800 8장, bfloat16 혼합 정밀도. AdamW, grad clip 1.0, warmup 1k, 코사인 감쇠 2.5e-5 → 2.5e-6. 글로벌 배치 32(인코더) / 8(정책). 정책은 7개 태스크 전체에 대해 단일 정책으로 80k step 학습, 인코더는 첫 5k step 동결 후 end-to-end.

## 9. 소거 실험 (Table 3, 7태스크 평균 %)

| Variant | Avg | Δ |
|---|---|---|
| Full ReTouch | **83.6** | — |
| w/o intra-chunk refinement | 60.0 | −23.6 |
| w/o tactile-prediction refinement | 68.4 | −15.2 |
| w/o future tactile prediction | 67.6 | −16.0 |
| non-blocking joint refinement | 75.8 | −7.8 |
| w/o Tactile-Patch Encoder | 69.1 | −14.5 |

가장 결정적인 발견은 **68.4 vs 67.6의 0.8%p 차이**다. "액션은 갱신하되 초기 촉각 예측을 고정"(68.4)과 "미래 촉각 예측을 아예 제거"(67.6)가 거의 같다는 것은, **고정된 one-shot 촉각 예측은 사실상 무가치**하며 이득의 대부분이 예측을 계속 갱신하는 데서 온다는 뜻이다. 이는 논문의 핵심 주장을 가장 날카롭게 뒷받침하는 수치다.

non-blocking 변형(−7.8)은 실행을 멈추지 않고 병렬 갱신해 각 갱신이 약 1 액션 스텝 늦게 반영되는데, 이 지연만으로 7.8%p가 소실된다 — 갱신의 **적시성**이 중요함을 보여준다. Tactile-Patch Encoder 제거(원시 촉각 평탄화 + MLP)는 −14.5%p로, 손가락 정체성과 국지 영역 구조 보존의 가치를 확인한다.

**오프라인 진단 (Figure 5, 홀드아웃 100 궤적, 접촉 이후 구간)**: 오프셋 4/8/12에서 잠재 코사인 유사도는 ReTouch 0.9835/0.9857/0.9878 vs one-shot 0.9382/0.9453/0.9523, 액션 MSE는 0.0143/0.0135/0.0151 vs 0.0174/0.0212/0.0250. 평균적으로 잠재 유사도 +0.908%, 액션 오차 −2.139%이며, **오차 감소 폭이 갱신을 거듭할수록 커진다**. 접촉 이전 구간에서는 촉각 신호가 대체로 0이라 두 전략이 유사하다.

## 11. 강점과 한계

**강점**

- 문제 진단이 정확하고, 소거 실험(특히 68.4 vs 67.6)이 그 진단을 직접 검증한다. "예측을 제어 상태로 재정의"라는 개념적 기여가 수치로 뒷받침되는 드문 사례다.
- Tactile-Patch Encoder는 손가락당 토큰 1개(프레임당 5개)라는 매우 절약적인 토큰 예산으로 위상 정보를 유지한다 — 정책 컨텍스트 예산 측면에서 실용적이다.
- 방향성 어텐션 마스크로 액션→촉각 정보 누출을 차단한 설계가 깔끔하다.
- 7개 베이스라인(ACT 계열, diffusion 계열, 촉각 VLA, π 계열 ±촉각)을 동일 플랫폼·동일 18차원 명령 공간·동일 16-step 청크로 재현한 비교가 성실하다.

**한계**

- **표준 시뮬레이션 벤치마크가 전무하다.** LIBERO·CALVIN·SimplerEnv 등 결과가 없어 커뮤니티 차원의 직접 비교가 불가능하고, 성능은 자체 구축 XHT-Dataset과 자체 채점 루브릭에 전적으로 의존한다.
- 채점이 **단일 평가자가 현장에서 적용하는 고정 루브릭**이며 대부분 태스크가 단계별 부분 점수다. 블라인드 평가나 평가자 간 신뢰도 보고가 없다.
- 태스크당 20회 롤아웃은 실기 연구로서 통상적이나, 5%p 내외 차이를 논하기에는 통계적 여유가 크지 않다(분산·신뢰구간 미보고).
- 파라미터 수가 명시되지 않았고, 코드·데이터 공개 언급이 없어 재현이 어렵다.
- XHand 특유의 T30/T16 고정 택셀-패치 맵에 인코더가 결속되어 있어, 다른 촉각 하드웨어로의 이식성이 검증되지 않았다.
- Cabinet Retrieval에서 ViTacFormer에 뒤지는데(62.5 vs 67.5), 시각 가림 하 장기 다단계 태스크에서의 약점에 대한 분석이 얕다.
- 학습 오프셋이 `{4, 8, 12}`로 고정되어 있어 임의 시점 갱신에 대한 일반화는 확인되지 않았다.

## 12. VLA-Tracker 관점에서의 위치

ReTouch는 π0 체크포인트에서 초기화된 **flow matching 계열 촉각 인지 VLA**로, tracker 내 촉각 계열(Tactile-VLA, ViTacFormer, RDP, OmniVTLA 등)과 비동기 고속 액션 전문가 계열(π0/π0.5 파생) 사이에 위치한다. 특히 "고속 전문가가 액션뿐 아니라 **예측 자체를 재추정**한다"는 축은 기존 predictive-reactive 방식들과 구분되는 명확한 좌표를 제공한다.

다만 표준 벤치마크 점수가 없어 leaderboard의 `libero_avg` 기반 순위에는 진입하지 않으며, `benchmarks.real_world` 항목으로만 기록된다. 실기 전용 덱스터러스 조작 모델을 추적할 때 참조점으로서 가치가 있고, 향후 촉각 VLA 항목이 늘어날 경우 "예측 갱신 주기(청크 단위 vs 고속 호출 단위)"를 별도 메타데이터 축으로 두는 것이 유용할 수 있다.
