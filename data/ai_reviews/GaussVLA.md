# GaussVLA — Geometry-Aware Spatial Reasoning for Vision-Language-Action Model

- arXiv: 2608.24959 (2026-08-25), BMVC 2026
- 소속: 영남대학교, 경북대학교 (Md Selim Sarowar, Md Tanvir Islam, Sungho Kim, Sangtae Ahn)

## 1. 한 줄 요약

GaussVLA는 SigLIP 패치 특징과 Depth-Anything-V2 깊이를 3D 가우시안 토큰으로 끌어올리는 **Gaussian Spatial Tokenizer(GST)**와, 소수의 학습 쿼리로 비자기회귀적 기하 추론을 하는 **Depth-Aware Chain-of-Thought(DA-CoT)**를 Mamba 정책 백본에 결합한 경량 VLA다. 외부 고정 인코더를 뺀 전체 200M(학습 179M) 파라미터로 LIBERO 평균 93.5%, Spatial 스위트 100.0%를 기록했다. 다만 LIBERO-PRO(0.33)에서는 비교 대상 중 가장 낮고, CALVIN은 표준이 아닌 ABCD→D 10% 설정에서 평균 길이 1.474다.

## 2. 문제 설정

기존 VLA는 RGB를 평평한 2D 패치 토큰으로 다뤄 metric 3D 구조가 없다. 깊이를 더하는 방법도 픽셀별 스칼라 값이라 표면 방향이나 깊이 추정의 신뢰도를 담지 못한다. 자기회귀 CoT(ECoT, CoT-VLA)는 2D 이미지 좌표에서 추론하고 토큰을 순차 생성하느라 지연이 크다. 저자들은 (1) 구조화된 3D 표현, (2) 행동 디코딩과 결합된 빠른 기하 추론, (3) 선형 시간 시퀀스 모델링을 한 모델에 담고자 한다.

## 3. 핵심 아이디어

- **GST**: 각 패치를 평균(3D 위치), 공분산(국소 기하·범위), 불투명도(신뢰도)를 가진 가우시안 원시로 바꾸고, 신뢰도 편향이 들어간 공간 어텐션 풀링으로 압축한다.
- **DA-CoT**: 4개의 추론 쿼리가 GST 토큰, 언어, flow 시간을 문맥으로 교차 어텐션해 구조화된 추론 토큰을 만든다. 텍스트를 생성하지 않으므로 지연이 작다.
- **Mamba 백본 + flow-matching 디코더**: 멀티모달 시퀀스를 선형 시간으로 처리하고, GST 토큰에 대한 전역 교차 어텐션으로 선형 스캔이 개별 원시를 다시 읽지 못하는 문제를 보완한다.

## 4. 방법 상세

- **이중 스트림 인코딩**: 고정 SigLIP-SO400M/14로 256개 패치 특징(d_s=1152)을, 고정 Depth-Anything-V2(ViT-L)로 깊이 지도를 얻고 패치 중심에서 샘플링한다.
- **역투영**: 학습 가능한 아핀 보정 d̃ = λ_d·d + β_d 후 카메라 내부 행렬로 c = d̃·K⁻¹u를 계산한다.
- **가우시안 파라미터**: 의미 특징에서 잔차 평균 Δμ, 로그 스케일 η, 불투명도 α를 예측한다. μ = c + ρ·tanh(Δμ)이고 작업 공간 반경 ρ는 0.8 m다. μ에는 L=10 대역의 3D 푸리에 인코딩을 적용한다. 토큰은 [f ⊕ γ(μ) ⊕ η]로 만든다.
- **신뢰도 풀링**: 카메라당 N_g=128개의 학습 쿼리가 softmax(QKᵀ/√d + log α) 형태의 어텐션으로 패치를 풀링한다. α는 의미 특징에서만 예측되고, 깊이 인식은 불투명도 가중 깊이 일관성 손실을 통해 간접적으로 생긴다.
- **DA-CoT**: GST 토큰 전체를 평탄화하고, 언어 토큰과 시간 토큰을 붙여 문맥 C_τ를 만든다. N_r=4개 쿼리가 자기 어텐션 → 교차 어텐션 → FFN을 거쳐 R_τ가 된다.
- **정책**: [시간, 언어, GST, DA-CoT, 행동] 토큰을 Mamba 블록 5개(d_b=512)로 처리한다. 행동 디코더(교차 어텐션 블록 2개)가 문맥 상태, DA-CoT 토큰, 시간 임베딩을 참조해 속도장을 예측한다. H=10, 7-DoF, Euler 10스텝.
- **손실**: L = L_FM + L_GST + L_CoT. L_GST는 가우시안 평균의 z 좌표와 보정 깊이 사이의 α 가중 L1이다. L_CoT는 DA-CoT 요약을 행동 디코더 출력에 더해 보조 속도를 예측하게 한다. 구현 가중치는 λ_GST 0.05, λ_CoT 0.10에 5 에포크 워밍업을 쓴다.

## 5. 학습 설정

- SigLIP, Depth-Anything-V2, CLIP 텍스트 인코더는 모두 고정한다. GST, DA-CoT, Mamba 백본, 행동 디코더만 처음부터 학습한다.
- AdamW(lr 2.5e-5, wd 1e-4), 배치 256, BF16, cosine 스케줄, flow 시간 ~ Beta(1.5, 1.0).
- 추론은 RTX Pro 6000 Blackwell에서 12.97 ms/step이다. 이 중 고정 인코더가 8.50 ms, 학습 모듈이 4.47 ms다. 실로봇 추론은 GeForce 1080 Ti에서 돌렸다.
- 실로봇 SO-101은 RealSense 640×480 60 Hz, 제어 15 Hz, 과제당 원격조작 시연 50개다.

## 6. 실험 설정

- LIBERO(과제당 40회 롤아웃), LIBERO-PRO(물체, 위치, 의미, 과제, 환경 교란), Meta-World(Easy/Mid/Hard/Very Hard), CALVIN ABCD→D(10% 부분 집합 학습)를 평가한다.
- 실로봇: SO-101 단일 팔. 다중 과제(Pick-Place, Stacking, Sorting)와 카메라를 ±5 cm, ±10° 옮긴 Pick-Place OOD.

## 8. Meta-World, CALVIN, LIBERO-PRO, 실로봇 (Table 2, 3, 13, 본문)

- **Meta-World**: Easy 92.7, Mid 47.9, Hard 37.3, Very Hard 41.6, 평균 54.9다. Easy와 평균은 π0(평균 47.9)보다 높지만, Mid와 Hard는 π0(48.2, 41.7)가 더 높다.
- **CALVIN ABCD→D(10%)**: 1–5개 연속 성공률 0.637 / 0.367 / 0.291 / 0.179 / 0.000, 평균 길이 1.474로 GR-1(2.0)보다 낮다. 부록에서 청크 길이 H=20으로 바꾸면 1.65, H=50이면 1.32다.
- **LIBERO-PRO**: 정규화 성공률 평균 0.33으로 OpenVLA(0.52), π0.5(0.53), π0(0.44)보다 낮다. 위치(Pos)와 과제(Task) 교란에서는 4개 스위트 모두 0.00이다.
- **실로봇 SO-101**: 다중 과제 평균 58.8%로 SpatialVLA 46.3%, ACT 35.7%보다 높다. Pick-Place는 ID 81.0%, OOD 46.7%로 SpatialVLA보다 각각 12.0, 10.9포인트 높다. 과제별 수치는 Fig. 4에만 있다.

## 9. 어블레이션 (Table 4, 5, 9–12)

- **구성 요소**: Vanilla(2D 토큰) LIBERO 78.1 / PRO 11.2 → GST만 90.5 / 29.0 → DA-CoT만 82.1 / 16.7 → 전체 93.5 / 33.3. GST가 주된 이득을 낸다. 지연은 10.85 → 12.97 ms, GFLOPs는 3.50 → 4.83으로 는다.
- **쿼리 수**: N_g를 8에서 128로 늘리면 86.4 → 93.5이고, 256에서는 93.6으로 포화된다. N_r은 4가 최적이다(1개 91.8, 16개 92.9).
- **백본**: Transformer + 표준 헤드 67.49, Mamba + 표준 헤드 73.36, Mamba + 행동 디코더 78.1.
- **GST 설계**: 2D 패치에 깊이를 단순히 이어 붙이면 LIBERO가 78.1에서 73.3으로 오히려 떨어진다. 전체 GST는 90.5다. 깊이 자체보다 구조화된 가우시안 표현이 중요하다는 주장의 근거다.
- **신뢰도 편향 제거**: LIBERO 93.5 → 91.6, PRO 33.3 → 29.7.
- **탐침(Table 8)**: 물체 3D 위치 R²가 2D 패치 0.34 → GST 0.66 → DA-CoT 0.78로 오른다. 학습된 α와 깊이 불확실성 대리 지표의 Pearson 상관은 +0.47~+0.61이다.

## 10. 강점

- 3D 가우시안 원시를 VLA 토큰화에 들여온 참신한 설계다. 평균·공분산·불투명도 각각에 기하적 의미를 부여하고, 탐침과 상관 분석으로 그 해석을 뒷받침하려 했다.
- 외부 인코더를 뺀 200M 파라미터와 13 ms 지연으로 7B급 VLA들보다 높은 LIBERO 평균을 낸다. 경량·저지연 VLA로서 실용성이 있다.
- "깊이 단순 결합은 오히려 해롭다"는 부정적 결과를 포함한 세밀한 어블레이션이 풍부하다.
- 한국 대학 연구진의 BMVC 2026 논문이다.

## 11. 한계

- **강건성 약점**: LIBERO-PRO 0.33은 비교 대상 중 가장 낮고, 위치·과제 교란에서는 전부 0이다. 저자들도 시점 일반화와 언어 강건성의 한계를 인정한다. LIBERO 고득점이 분포 내 기억에 가깝다는 해석이 가능하다.
- **보고의 일관성 문제**: Table 1의 파라미터 열에는 "1B"로 적혀 있지만 본문은 200M이다. π0 LIBERO 수치(86.0)와 CoT-VLA 평균(82.43)도 흔히 인용되는 값과 다르다. Meta-World 인용도 McLean 등(Meta-World+)과 QueST 참조가 섞여 있다.
- **CALVIN 설정**: 표준 ABC→D가 아니라 ABCD→D 10% 부분 집합이며, 5개 연속 성공은 0.000이다.
- 대규모 로봇 사전학습 없이 벤치마크별로 처음부터 학습하므로 일반화 능력이 제한적이다. 코드 공개 여부도 명시되지 않았다.
- 실로봇은 단일 SO-101 팔에서의 단순 과제이고 과제별 수치가 그림에만 있다.

## 12. VLA-Tracker 관점 평가

GaussVLA는 GST, DA-CoT, Mamba 백본, flow-matching 디코더를 직접 학습한 자체 정책이므로 수록 기준을 충족한다. LIBERO 평균 93.5%를 libero 블록에, LIBERO-PRO 평균 33.3(Table 4; Table 3 정규화 0.33)을 libero_pro_avg로 넣고, 교란별 0–1 값은 별도 블록으로 분리했다. Meta-World는 metaworld 블록에 넣었다. CALVIN은 ABCD→D 10% 설정이라 표준 calvin 블록이 아닌 별도 블록에 기록했다. 소형·저지연 3D 인식 VLA 계열(SUREFlow, MaIL, RoboMamba)과 비교할 때 유용하다. 다만 LIBERO-PRO 약점과 표 내부의 불일치를 고려하면 LIBERO 순위만으로 성능을 판단해서는 안 된다.
