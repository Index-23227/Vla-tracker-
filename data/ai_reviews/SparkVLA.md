# SparkVLA — Stop-Aware Hierarchical VLA with Adaptive Action Chunking for Long-Horizon Manipulation

**arXiv**: 2608.16172 · **기관**: Beijing Institute of Technology, Tsinghua University · **날짜**: 2026-08-17

## 1. 한 줄 요약
계층형 VLA의 매 재관측 시점에서 "하위 과제를 끝낼지(Stop)"와 "액션 청크를 몇 스텝 실행할지"를 하나의 후보 집합 {Stop, 1..H}에 대한 단일 랭킹으로 통합하고, 오프라인 순서 선호만으로 학습해 RoboCerebra 47.12%, LIBERO 98.5%를 달성한 π0.5 기반 계층형 VLA.

## 2. 문제 설정
- 장기 조작에서 계층형 VLA(고수준 VLM 플래너 + 저수준 VLA 실행기)는 인터페이스 결정, 특히 종료 조건과 실행 지평이 성능을 좌우한다.
- 기존 방법은 종료(이진 검출기, VLM 예측 길이, 진행도 신호)와 지평 선택(DEHP, ACH, AQC, AAC)을 따로 결정한다. 그러나 최적 정지 시점은 실행기가 무엇을 하려는지에, 최적 실행 길이는 하위 과제 경계가 어디인지에 의존하는 상호 의존 관계다.

## 3. 핵심 아이디어
- **통합 후보 집합** C = {0(Stop), 1, …, H}: 제안된 청크 A_t의 각 접두부 길이와 Stop을 같은 점수 헤드로 평가하고 argmax를 선택 → 임계값 튜닝 불필요.
- **Anchor-Conditioned Context Encoding**: 하위 과제 시작 시 플래너의 끝에서 두 번째 층에서 앵커를 추출하고 이전 앵커 이력과 self-attention으로 융합해 캐시. 이 앵커로 Grid-Sampler 기반 시각 토큰 가지치기(카메라당 K=32 토큰)를 유도.
- **Stop-Aware Action-Prefix Selection**: 후보 토큰(각 접두부의 마지막 액션 + 길이 임베딩, 학습된 Stop 임베딩)과 문맥 토큰이 전체 self-attention으로 상호작용하는 2층·8헤드 트랜스포머 점수기.

## 4. 아키텍처
- π0.5에서 파생된 두 개의 별도 파라미터 브랜치: 고수준 브랜치(π0.5 VLM 백본, 하위 과제 명령 자기회귀 생성 + 선택기 호스팅), 저수준 브랜치(액션 전문가 포함 π0.5 전체, H=50 액션 청크 제안).
- SigLIP 인코더 동결, 입력 224×224, 앵커 폭 2,048, 고수준 깊이 ℓ_m=8층, LoRA rank 16(1–8층), 점수 폭 1,024.
- 추론: 선택기는 청크 경계에서만 호출. 명령 캐싱(2.91× 가속)과 경계 호출(2.10× 가속)로 4.14 Hz 실행, 단독 π0.5(4.68 Hz)의 88% 처리량.

## 5. 학습 목표
- 쌍별 랭킹 손실: 오프라인 실행 결과로부터 순서 우선순위 ρ 부여. 완료 후에는 Stop 최상위, 완료 전에는 경계를 덮는 접두부가 덮지 못하는 접두부보다 우선하고 그중 초과가 적은 것 선호, 실패 롤아웃에서는 모든 접두부가 Stop보다 위(동률).
- Stop-aware 보조 손실: Stop 점수 대 연속 점수 log-sum-exp 대비 BCE. 경계 라벨은 τ' = τ + Δ, Δ∼U{−2..2}로 교란.
- 총 손실 L = L_rank + λ_stop·L_stop (λ_stop=1).

## 6. 학습 절차
- 플래너와 실행기를 각각 사전학습 π0.5에서 대상 데이터로 파인튜닝 → 플래너를 하위 과제 명령 예측으로 2,000 step 지도학습 → 두 베이스 브랜치를 동결하고 선택기 모듈(LoRA, 앵커/가지치기/점수 헤드)을 20,000 step 학습.
- 선택기 데이터: 시연 6,660개 + 정책 롤아웃 5,630개에서 2,034,310개 결정 샘플 구성(시연 30%, 롤아웃 70% 혼합). A100 80GB 4장, 배치 256.
- 즉 π0.5 두 브랜치의 파인튜닝과 선택기 학습이 모두 포함된 자체 학습 정책.

## 11. 강점과 한계
**강점**
- 종료와 실행 지평의 상호 의존성을 단일 랭킹으로 풀어낸 명료한 문제 정식화. 임계값 없이 오프라인 순서 라벨만 사용.
- 시뮬레이션(RoboCerebra, LIBERO)과 실제 로봇 모두에서 일관된 향상, 실행기 교체 실험으로 일반성 확인.
- 체계적인 어블레이션으로 각 설계 요소의 기여 분리.

**한계**
- π0.5 두 벌을 운용하므로 메모리·연산 부담이 크고 처리량이 단독 π0.5보다 낮음(4.14 vs 4.68 Hz).
- 하위 과제 경계 주석(시뮬레이션은 LaRA-VLA 주석, 실제는 분할된 시연)에 의존.
- 표 1의 기준선 대부분은 저자 재현이며, 온라인 적응·개방형 환경은 다루지 않음(저자 명시).

## 12. VLA-Tracker 관점 평가
SparkVLA는 π0.5 플래너·실행기 파인튜닝과 선택기 학습을 포함하는 자체 학습 계층형 VLA이므로 ACCEPTED. 저수준 액션은 π0.5의 flow-matching 액션 전문가가 생성하므로 `action_head_category: flow_matching`. LIBERO 4개 스위트와 논문이 직접 보고한 평균 98.5를 `benchmarks.libero`에 등록했고(추적 벤치마크), RoboCerebra 본 결과·실행기 변형·기준선·어블레이션·실제 로봇 결과는 각각 별도 블록으로 분리했다.
