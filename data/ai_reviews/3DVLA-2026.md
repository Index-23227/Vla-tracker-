# 3DVLA-2026: Enhancing Vision-Language-Action Models via 3D Spatial and Instance Understanding

> **한 줄 요약**: 사전 학습된 VLA(π₀, π₀.₅, X-VLA) 위에 ~0.086B 파라미터만 얹어 (1) Spatially-Conditioned Geometry Aggregation으로 2D feature를 3D geometry와 융합, (2) 300개 state probe에서 distilled된 최대 16개 instance token, (3) masked 3D self-supervised pretraining의 3-component를 더하는 plug-and-play 3D 증강 framework. LIBERO-Plus 86.0%, RoboTwin 2.0 (X-VLA+3DVLA) Easy 72.6%/Hard 42.1% 달성. **주의: 2024년 3D-VLA 논문과 동명이지만 완전히 다른 작업**.

---

## 1. 배경 및 동기

### 기존 VLA의 3D 인지 결핍
- π₀, π₀.₅, OpenVLA 같은 SOTA VLA는 DINOv2/SigLIP의 2D feature에 전적으로 의존 → depth, 6-DoF pose, occlusion에 본질적으로 약함
- LIBERO-Plus의 *camera/robot perturbation* 카테고리에서 모든 baseline의 성능이 급락 → 3D-blind한 정책의 robustness 한계 노출
- 별도의 3D 전용 VLA(3D-VLA 2024, SpatialVLA)는 처음부터 다시 학습해야 하므로 비싼 대안

### 핵심 질문
- **이미 학습된 VLA를 처음부터 재학습 없이** 3D 인지로 강화할 수 있는가?
- 작은 파라미터(0.086B)로 의미 있는 3D robustness 향상이 가능한가?

## 2. 방법론 심층 분석

### 2.1 세 가지 핵심 컴포넌트

| 컴포넌트 | 역할 | 비용 |
|----------|------|------|
| Spatially-Conditioned Geometry Aggregation | 2D feature를 explicit 3D 좌표로 lift 후 voxel/depth-aware aggregation | 주된 파라미터 비용 |
| Instance Token (300 probe → 16) | 장면 내 instance 후보 300개를 학습된 query로 reduce, 최대 16개 instance token만 정책에 전달 | 가벼움, attention bottleneck 역할 |
| Masked 3D Self-Supervised Encoding | Occluded depth/point cloud 패치 복원으로 3D encoder pretraining | Pretraining 비용만 |

총 추가 파라미터: **~0.086B** (Qwen-VLA 5.15B의 1.7% 수준)

### 2.2 Plug-and-play 적용 방식
- Base VLA의 vision encoder 출력을 hook하여 3D 모듈로 전달
- Instance token이 base VLA의 prompt token sequence에 prepend됨
- Action head는 그대로 — 행동 분포 변경 없음

> ❓ **예상 질문**: 왜 instance token을 16개로 제한하는가?
> **답변**: Attention 비용은 token 수에 quadratic. 16개로 제한하여 base VLA의 추론 latency를 거의 변화시키지 않음. 300 → 16은 set-of-tokens cross-attention으로 학습된 reduction.

> ❓ **예상 질문**: 0.086B로 86% LIBERO-Plus 가능한가?
> **답변**: Base VLA(π₀.₅)가 이미 84.2% 달성한 상태. 3DVLA는 +1.8%p 향상. 실제 핵심은 *Camera 75.6%, Robot 77.4%* 등 *3D 변형 카테고리*에서의 robustness 향상.

## 4. 실험 결과 심층 분석

### 4.1 LIBERO-Plus (Table 1, π₀.₅ + 3DVLA)

| Perturbation | Score |
|--------------|-------|
| Camera | 75.6 |
| Robot | 77.4 |
| Language | 88.6 |
| Light | 97.4 |
| Background | 97.7 |
| Noise | 85.3 |
| Layout | 86.6 |
| **Avg** | **86.0** |

- π₀.₅ baseline 84.2% → **+1.8%p** with only 0.086B added params
- **Camera/Robot/Layout** 카테고리(3D 변형)에서 향상이 두드러져야 하나, light/background(2D 변형)에서 이미 97%대이므로 3D가 boost한 부분 분리 필요

### 4.2 RoboTwin 2.0 (Table 2)

| Backbone | Easy | Hard |
|----------|------|------|
| π₀ baseline | 46.4 | 16.3 |
| **π₀ + 3DVLA** | **54.5 (+8.1)** | **23.2 (+6.9)** |
| X-VLA baseline | 70.0 | 39.0 |
| **X-VLA + 3DVLA** | **72.6 (+2.6)** | **42.1 (+3.1)** |

- **π₀ 약한 baseline에서 향상 폭이 큼** (+8.1, +6.9) — 약한 모델일수록 3D 보강의 한계 효용이 큼
- 강한 baseline(X-VLA)에서는 +2.6/+3.1로 marginal

### 4.3 Multiple-backbone consistency
- π₀, π₀.₅, X-VLA 세 가지에서 모두 향상 → plug-and-play 주장의 강력한 근거
- 단 향상 폭이 backbone마다 다르므로 "보편적" 향상은 아님

## 5. Ablation 분석
- 본문에 세부 ablation 부재 — 3개 컴포넌트 각각의 기여가 분리되지 않음
- Geometry aggregation alone? Instance tokens alone? Masked SSL alone? 모두 부재

---

## 6. 한계 및 미해결 문제

### 방법론적 미비점
1. **이름 충돌**: 2024년 3D-VLA(BLIP2 기반 generative world model)와 동명 — 학계 혼란 우려
2. **3D 변형 카테고리에서의 baseline 분리 부재**: Camera 75.6, Robot 77.4가 baseline π₀.₅의 같은 카테고리 대비 얼마나 향상됐는지 표가 없음
3. **Code 미공개**: "upon publication" 약속만 있음
4. **3D pretraining 데이터 미명시**: 어떤 indoor scene dataset인지 모름 → 재현 어려움
5. **CALVIN/SimplerEnv 평가 부재**: 핵심 long-horizon 및 generalization 벤치마크에서의 검증 없음

### Attribution 문제
- 0.086B 추가로 +1.8%p가 정말 *3D 이해* 덕분인지, 단순히 추가 capacity 덕분인지 분리 불가 (random 0.086B head ablation 부재)
- Instance token 16개의 정보가 정말 instance-aware한지 검증 부족 (시각화나 probing 부재)

## 7. 총평

| 항목 | 평가 |
|------|------|
| **Novelty** | ★★★☆☆ — Plug-and-play 3D enhancement는 새롭지 않음(SpatialVLA 등) — 0.086B 경량성이 차별점 |
| **Technical depth** | ★★★☆☆ — 3 컴포넌트는 직관적이나 깊은 분석 부재 |
| **Experimental rigor** | ★★★☆☆ — 3 backbone × 2 benchmark는 적절, ablation 부재 |
| **Practical impact** | ★★★★☆ — 경량 plug-and-play는 실용적 매력 |
| **Writing quality** | ★★★☆☆ |

**강점**: 0.086B만으로 3개 backbone에서 일관된 향상. LIBERO-Plus 86%는 robust manipulation에서 의미 있는 성과. **약점**: Ablation 부재, 이름 충돌, code 미공개. *3D 보강*이라는 주장의 실험적 근거는 perturbation 카테고리별 분해 없이는 약함.
