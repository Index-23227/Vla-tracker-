# ForeTime-VLA — Causal Future-Token Distillation from a World Action Model for Conveyor-Belt Manipulation

- arXiv: 2608.20735 (v2, 2026-08-24)
- 소속: 칭화대학교, 상하이 AI 연구소, 하얼빈공업대학, DEEP Robotics(杭州云深处)

## 1. 한 줄 요약

ForeTime-VLA는 고정된 Fast-WAM/Wan2.2 비디오 잠재 파이프라인이 미래 프레임으로 만든 64차원 "행동 등가" 미래 코드를 오프라인 교사로 삼고, 과거 8프레임만 보는 1.251M 파라미터 인과 학생이 이 코드와 조작 단계, 다음 전환까지 남은 시간을 예측하게 한다. 예측값은 π0.5의 VLM 프리픽스(느린 경로)와 행동 전문가(빠른 경로)를 동시에 조건화하며, 추론 시에는 월드 모델도 미래 프레임도 쓰지 않는다. 컨베이어 벨트 실로봇 평가에서 정지 물체 81.1%, 저속 이동 물체 58.9%의 파지 성공률로 π0.5(65.6%, 36.7%)를 앞선다.

## 2. 문제 설정

컨베이어 위에서 움직이는 물체를 집으려면 지금 보이는 것뿐 아니라 물체가 **언제** 도달 가능 영역에 들어오고, 그리퍼를 **언제** 닫고, 접촉 순간 엔드이펙터를 **어떻게** 기울일지 예측해야 한다. 현재 관측만으로 시연 행동을 재구성하도록 파인튜닝된 VLA는 이런 시간 구조를 간접적으로만 배운다. 월드 행동 모델(WAM)은 미래 예측 감독을 주지만, 추론 루프에서 비디오를 생성하는 "상상 후 행동" 방식은 비용이 크다. Fast-WAM은 비디오 모델링이 학습 신호로서 특히 유용하고 추론에서는 뺄 수 있다고 보고했다. 이 논문은 사전학습된 VLA가 WAM을 배포하지 않고도 그 예측 구조의 압축판을 얻을 수 있는지 묻는다.

## 3. 핵심 아이디어

- **교사–학생 분리**: 미래 프레임을 보는 특권 교사는 오프라인에서만 쓰고, 배포되는 학생은 과거 이력만 본다.
- **행동 등가 코드**: 미래 비디오 특징을 그대로 맞추는 대신 시연 행동을 재구성하도록 제약된 64-D 코드로 압축해, 제어와 무관한 외관 변화를 걸러낸다.
- **이중 경로 조건화**: 미래·단계 토큰은 의미를 다루는 VLM 경로에, 미래 코드와 전환 시간은 행동 전문가에 직접 주입한다.
- **행동 타깃 불변**: 교사가 만든 의사 행동으로 라벨을 바꾸지 않고, 기록된 행동 청크를 flow-matching 타깃으로 그대로 쓴다.

## 4. 오프라인 행동 등가 미래 교사

- 각 학습 창에서 현재 프레임과 오프셋 {2,4,7,9,12,14,17,19}의 미래 8프레임을 뽑아 고정된 Wan2.2 비디오 VAE(Fast-WAM의 시각 잠재 파이프라인)로 부호화하고, 시공간 평균·표준편차로 96-D 현재 특징 c_t와 96-D 미래 특징 f_t를 만든다.
- 처음 추출한 코드의 분산이 부족해 붕괴하지 않는 어댑터를 따로 학습했다. 특권 교사 인코더 g_T(c_t, f_t, s_t)와 인과 보조 인코더 g_C(c_t, s_t)가 각각 64-D 코드를 내고, 공유 행동 디코더가 20×16 정규화 행동 청크를 재구성하며, 교사 코드는 미래 디코더로 f_t − c_t도 재구성한다.
- 손실은 교사·인과 행동 MSE, 미래 smooth-L1, 교사–인과 코사인, 차원별 분산, 비대각 공분산, 쌍별 행동 기하 항이며 가중치는 각각 1.0, 0.5, 0.25, 0.10, 0.20, 0.01, 0.05다. 학습 후 차원별로 백색화한 교사 출력 z_T만 캐시한다.

## 5. 인과 시간 학생과 이중 경로 조건화

- **입력**: 8스텝 이력의 26-D 정규화 상태와 12-D 시각 통계(보조 카메라 2대의 채널별 평균·표준편차). 현재 고해상도 이미지는 원래대로 π0.5 비전 백본에 들어간다.
- **인코더**: e_i = swish(W_s LN(s_i)) + swish(W_v LN(r_i)) + p_i (256-D), 평탄화 후 2층 잔차 MLP.
- **헤드**: 64-D 미래 코드 ẑ_t, 4개 조작 단계 로짓(접근, 파지/해제 전환, 운반, 배치/후퇴), 시그모이드 정규화 전환까지 시간 d̂_t. 단계와 전환 시간 라벨은 그리퍼 상태 전환에서 저비용으로 얻는다.
- **느린 경로**: ẑ_t를 2048-D 미래 토큰 4개로 사상하고, 예측 단계 분포 하의 기대 임베딩을 5번째 토큰으로 더해 π0.5 프리픽스에 붙인다.
- **빠른 경로**: ẑ_t와 d̂_t를 1024-D 잔차로 사상해 모든 행동 전문가 suffix 토큰과 적응 정규화 조건에 더한다. 두 주입 모두 0.05로 초기화된 학습 가능한 스칼라 게이트를 거친다.
- 추가 모듈은 1.251M 파라미터로, Gemma-2B VLM과 311M 행동 전문가에 비해 작다.

## 6. 학습 목표와 데이터

- 총 손실: L = L_flow + 0.20·L_cos + 0.02·L_geo + 0.04·L_phase + 0.04·L_transition + 0.05·L_ae. L_cos는 행 정규화한 예측·교사 코드의 코사인, L_geo는 배치 Gram 행렬 차이의 Frobenius 노름, 전환 시간은 δ=0.1 Huber, L_ae는 ẑ_t에서 선형 디코더로 행동 청크를 재구성한다.
- **π0.5의 모든 파라미터와 ForeTime-VLA 모듈을 함께 최적화**하는 전체 파라미터 파인튜닝이다.
- 데이터: 이동형 매니퓰레이터로 상자·옥수수·수박을 벨트 속도·시점·배치를 바꿔 가며 수집. 487개 HDF5 중 1개 손상, 28개 중복을 제외한 458 에피소드, 96,512프레임(15 Hz, 1.79시간). 에피소드 기준 402/31/25로 나눠 77,125/6,075/4,610개 행동 창을 얻었다. 행동은 16-D 절대 행동, 청크 길이 H=20, 카메라 3대.

## 9. 어블레이션과 효율

- **추론 시 구성요소 제거**(Table III, 같은 가중치에서 추론 시에만 마스킹, 테스트 96개 창과 전환 구간 48개 창): 전체 모델 MAE 0.118354, 전환 MAE 0.145320. 미래 조건 제거 시 전환 MAE 0.159982(+10.1%), 단계·시간 조건 제거 시 0.160672(+10.6%), 느린 경로만 0.156587, 빠른 경로만 0.161749다. 다만 전환 구간 EE-RPY MAE는 빠른 경로만 쓸 때(0.479751)가 전체 모델(0.482656)보다 낮다.
- 이 어블레이션은 학습된 모델에서 입력을 지운 것이지 해당 구성요소 없이 다시 학습한 것이 아니다. 따라서 "모델이 그 신호를 사용한다"는 증거일 뿐 "그 구성요소가 학습에 필요하다"는 증거는 아니다.
- **지연**: 검증 66.69→68.65 ms(+2.93%), 테스트 66.97→68.62 ms(+2.46%). GR00T(133.86/132.12 ms), StarVLA(101.72/97.24 ms)보다 빠르다.

## 10. 강점

- 비디오 월드 모델의 예측 구조를 배포 비용 없이(지연 +3% 미만) VLA에 이식하는 실용적인 교사–학생 설계다.
- π0.5와 같은 백본·초기화·데이터 분할·행동 타깃을 쓰는 통제된 비교이며, 쌍대 부트스트랩 신뢰구간을 보고하고 유의하지 않은 지표(MSE)는 주장하지 않는다.
- 오프라인 EE-RPY 개선, 실로봇 접촉 자세 오류 감소, 속도가 빨라질수록 커지는 격차가 같은 방향을 가리켜 메커니즘 해석이 설득력 있다.
- 실패를 조기·지연·접촉 자세로 나눈 결과 분석이 구체적이다.

## 11. 한계

- 단일 컨베이어 벨트 구현체와 자체 데이터셋(1.79시간)에 한정되며, LIBERO 같은 표준 벤치마크 결과가 없다. 저자들도 일반성 검증이 필요하다고 인정한다.
- 오프라인 개선 폭이 작다(MAE 2–3%). 설득력의 대부분은 실로봇 결과에서 나온다.
- 실로봇 결과가 "보고된 스프레드시트"의 집계로만 제시되고, 시행 순서나 조건 무작위화 절차가 설명되지 않는다. 속도 스트레스 테스트는 π0.5만 비교했다.
- 교사 어댑터의 초기 코드가 붕괴해 다시 설계하는 등, 교사 구성 과정의 선택이 사후적으로 보인다. 교사 없는 보조 손실(단계·전환 시간만)로 다시 학습한 어블레이션이 없어 WAM 증류의 순수 기여를 분리하기 어렵다.
- 비교 대상 GR00T N1.6, StarVLA, SmolVLA의 학습 설정(스텝, 하이퍼파라미터)이 공개되지 않아 교차 계열 비교의 공정성을 판단하기 어렵다.
- 코드 공개 여부가 명시되지 않았다.

## 12. VLA-Tracker 관점 평가

ForeTime-VLA는 π0.5 전체 파라미터를 공동 최적화해 자체 정책을 학습하고 정량 결과를 보고하므로 수록 기준을 충족한다. 표준 시뮬레이션 벤치마크 없이 컨베이어 벨트 실로봇과 자체 데이터셋 오프라인 오차만 있으므로 리더보드 순위에는 반영되지 않는다. YAML에는 Table IV의 실로봇 성공률과 실패 분해, 본문 V-G의 속도별 성공 횟수, Table I의 테스트 오차를 기록했고, π0.5·GR00T N1.6·StarVLA·SmolVLA 결과는 별도 블록으로 분리했다. Fast-WAM, DECOWAM 등 "학습 시에만 월드 모델을 쓰는" 계열과 동적 물체 조작 분야의 참고 사례로 분류할 만하다.
