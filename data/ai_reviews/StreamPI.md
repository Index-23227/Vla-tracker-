# StreamPI — Streaming Multimodal Temporal Modeling for Vision-Language-Action Models

- arXiv: 2608.26067 (2026-08-26)
- 소속: 홍콩대학교, ACE Robotics (Zhe Liu, Jinghua Hou 외, 교신저자 Hengshuang Zhao)
- 프로젝트: https://happinesslz.github.io/projects/StreamPI

## 1. 한 줄 요약

StreamPI는 단일 프레임 VLA인 π0.5에 **파라미터를 하나도 추가하지 않고** 시간 모델링을 넣는 방법이다. (다시점 관측, 언어 지시) 쌍을 하나의 원자 시간 단위로 묶어 쌍 내부는 양방향, 쌍 사이는 인과 어텐션을 쓰고, 추론 때는 KV 캐시로 과거 단위를 재사용한다. 학습 때 프레임 간격을 무작위로 바꿔 비동기 배포에 대비한다. π0.5 전체 파인튜닝으로 LIBERO 평균 98.3%(π0.5 96.9%), CALVIN 평균 길이 4.547(π0.5 4.313)을 기록했다. 실로봇 기억·정밀 지각 과제 4개에서도 π0.5보다 26.7–36.6%p 높다.

## 2. 문제 설정

π0/π0.5는 매 스텝 한 장면만 보고 행동한다. 그래서 과거를 기억해야 하는 과제(컵 섞기 게임, 굴러가는 물체 잡기)나 여러 프레임의 시차에서 얻는 정밀 3D 지각이 필요한 과제에 약하다. 창(window) 기반 다중 프레임 VLA는 계산량이 크거나 별도 비디오 인코더가 필요하다. 저자들은 네 가지 과제를 든다. (1) 프레임 수에 비례하는 계산 증가, (2) 시각 토큰이 쌓이면서 지시가 희석되는 지시 망각, (3) 규칙적 간격의 학습과 비동기적 실배포 사이의 불일치, (4) 새 모듈이 사전학습 표현을 망가뜨릴 위험이다.

## 3. 핵심 아이디어

- **지시 고정(instruction-anchored) 시간 모델링**: 매 프레임에 지시를 다시 붙여 u_t = (V_t, l_t)를 나눌 수 없는 단위로 만든다. 지시가 매 시점의 의미 기준점이 된다.
- **블록 인과 어텐션 마스크**: 쌍 내부는 양방향 어텐션으로 교차 모달 융합을 하고, 쌍 사이는 인과 어텐션으로 스트리밍 자기회귀 구조를 유지한다.
- **무작위 간격 스트리밍 학습**: 프레임 간격을 무작위로 섞고 앞쪽 프레임을 무작위로 가려 스트리밍 추론 조건을 흉내 낸다.
- **파라미터 무추가**: 어텐션 마스크와 위치 임베딩 확장만 쓰고, LLM의 길이 외삽 능력에 기대 π0.5 가중치를 그대로 물려받는다. 한 모델로 단일·다중 프레임 추론이 모두 가능하다.

## 4. 방법 상세

- **입력**: 최근 T개 샘플 관측 U = [u_{t−T+1}, ..., u_t]. π0.5의 전면·좌우 손목 3시점을 쓴다.
- **쌍 내부**: h_τ = Attn_bi(V_τ, l_τ). **쌍 사이**: o_t = Attn_causal(h_{t−T+1}, ..., h_t)이고, o_t가 행동 생성을 조건화한다.
- **무작위 간격 샘플링**: 기준 간격 δ̄에 ε ~ U(−Δ, +Δ)를 더하고 [δ_min, δ_max]로 자른다. 실험에서는 δ ~ U[3, 7]이다.
- **시간 마스킹**: k ∈ {0, ..., T−1}을 뽑아 가장 이른 k개 프레임을 가린다. 스트리밍 초기의 짧은 이력을 흉내 내는 장치다.
- **스트리밍 추론(Algorithm 1)**: 새 프레임만 인코딩하고 캐시된 과거 표현에 어텐션한다. 캐시가 T를 넘으면 비운다. 부록의 의사코드상 슬라이딩 창이 아니라 비우고 다시 채우는 방식이다.
- **지연(Table 6, RTX 4090)**: 1프레임 94.4 ms, 3프레임 97.9 ms, 5프레임 103.6 ms, 10프레임 117.9 ms.

## 5. 학습 설정

- π0.5에서 시작해 전체 파인튜닝한다. 옵티마이저와 학습률 스케줄은 π0.5와 같다.
- 스트리밍 프레임 T=3 또는 5, 학습 간격 δ ~ U[3, 7]. 추론 간격은 시뮬레이션에서 δ=5로 고정하고, 실로봇에서는 U[3, 7]에서 샘플링한다.
- H100 8장. LIBERO는 배치 256으로 30k 반복, 실로봇은 배치 128로 50k 반복.
- 실로봇: AgileX PiperX 6-DoF 팔(Aloha식 리더·팔로워), RealSense D455 전면 카메라 1대와 D435 손목 카메라 2대. 과제당 30 FPS 원격조작 시연 100개.

## 6. 실험 설정

- LIBERO 4개 스위트, 과제당 50회.
- CALVIN: "표준 평가 프로토콜"이라고만 적었고 ABC→D인지 ABCD→D인지 명시하지 않았다.
- 실로봇: 기억 의존 과제(Shell Game 15개 패턴, Rolling Object Grasping 30회)와 정밀 지각 과제(Pen Insertion 3개 패턴 × 10회, Cup Insertion 5개 위치 × 5회).

## 7. LIBERO와 CALVIN 결과 (Table 1, 2)

| 방법 | Spatial | Object | Goal | Long | 평균 |
|---|---|---|---|---|---|
| ST-π | 98.4 | 98.3 | 96.9 | 94.3 | 97.3 |
| MemoryVLA | 98.4 | 98.4 | 96.4 | 93.4 | 96.5 |
| π0.5 | 98.8 | 98.2 | 96.8 | 92.4 | 96.9 |
| StreamPI (T=3) | 98.6 | 98.6 | 98.6 | 93.8 | 97.5 |
| **StreamPI (T=5)** | 98.8 | **99.8** | **99.6** | **95.0** | **98.3** |

π0.5 대비 평균 +1.4%p, Long +2.6%p, Goal +2.8%p이고 Spatial은 같다. 같은 표의 다른 모델 평균 일부(예: SpatialVLA 71.7, OpenVLA 75.9)는 흔히 인용되는 값(78.1, 76.5)과 다르다.

CALVIN(Table 2): 1–5번째 과제 성공률 96.9 / 93.6 / 90.7 / 88.5 / 85.0, 평균 길이 4.547이다. π0.5는 4.313, MemoryVLA는 4.090이다. 5번째 과제에서 85.0% 대 79.5%(π0.5)로 뒤로 갈수록 격차가 커진다.

## 8. 실로봇 결과 (Fig. 3, 부록 Table 7–10)

| 과제 | π0.5 | StreamPI |
|---|---|---|
| Shell Game (15회) | 46.7 | **80.0** |
| Rolling Object Grasping (30회) | 26.7 | **63.3** |
| Pen Insertion into Narrow Bottle (30회) | 40.0 | **66.7** |
| Cup Insertion into Cup Sleeve (25회) | 60.0 | **92.0** |

Cup Insertion에서는 π0.5가 멀리 있는 컵 슬리브(Left-Far, Right-Far) 위치를 잘못 추정하는 경우가 많다. Pen Insertion은 정밀 지각뿐 아니라 "지금이 집는 단계인지 넣는 단계인지"를 아는 시간 정보도 필요하다. 참고로 본문 4.2절은 Shell Game 향상(+33.3%)을 "Cup Hiding and Retrieval"이라는 다른 과제명으로 적었다. 또 이 수치를 Shell Game 설명이 끝나기 전에 Rolling Object Grasping(+36.6%)과 함께 적어 서술 순서가 어색하다. 수치 자체는 부록 표와 일치한다.

## 9. 어블레이션 (Table 3–5)

- **어텐션 방향**: 쌍 내부를 인과 어텐션으로 바꾸면 모든 T에서 성능이 떨어진다(T=5: 98.3 → 95.5, Long 95.0 → 90.6). T=1 양방향(96.5)과 T=5 양방향(98.3)을 비교하면 쌍 사이 시간 집계의 이득이 +1.8%p다.
- **무작위 간격**: 고정 δ=1 학습(T=3 96.4, T=5 97.0) 대비 무작위 간격 학습이 T=3 97.5, T=5 98.3으로 높다. 간격이 크면 추론 빈도도 줄어 실행 시간 여유가 생긴다.
- **교차 스트림 일반화**: T=5로 학습한 모델을 T=3으로 평가하면 97.4, T=1이면 97.1이다. 단일 프레임으로 돌려도 π0.5 재현값(96.5)보다 높다. 여기서 π0.5 기준선 96.5는 Table 1에 인용된 96.9와 다른 저자 재현값이다.

## 10. 강점

- 파라미터를 추가하지 않고 어텐션 마스크만 바꿔 시간 모델링을 넣었다. 사전학습 표현을 보존하고 구현이 매우 간단하다.
- 지시를 매 프레임에 다시 붙이는 설계와 쌍 내부 양방향 어텐션의 효과를 어블레이션으로 명확히 보였다.
- KV 캐시로 5프레임에서 9.2 ms만 늘어 실시간 제어에 적합하다.
- 기억(Shell Game, 굴러가는 물체)과 정밀 지각(펜·컵 삽입) 두 축의 실로봇 과제를 설계하고, 시행별 결과표를 부록에 공개했다.
- 한 모델로 T=1/3/5 추론을 모두 지원한다.

## 11. 한계

- CALVIN 분할을 명시하지 않아 기존 ABC→D 결과와 직접 비교하기 어렵다.
- LIBERO는 이미 포화에 가까워 +1.4%p 향상의 의미가 제한적이다. π0.5 기준값도 표마다 96.9(인용)와 96.5(재현)로 다르다.
- 이력 길이가 T=5, 간격 3–7프레임 정도라 수 초 이내의 짧은 기억에 해당한다. 저자들도 초장기(>100프레임) 확장은 학습 비용 때문에 어렵다고 인정한다. 캐시를 비우고 다시 채우는 방식이라 캐시를 비운 직후에는 이력이 끊긴다.
- 실로봇 시행 수가 작고(15–30회), 본문의 과제명 표기(Cup Hiding and Retrieval)가 부록(Shell Game)과 다르다.
- 코드 공개 여부가 명시되지 않았다.

## 12. VLA-Tracker 관점 평가

StreamPI는 π0.5를 전체 파인튜닝한 자체 정책이며 LIBERO, CALVIN, 실로봇 정량 결과를 보고하므로 수록 기준을 충족한다. LIBERO 평균 98.3%(T=5)는 리더보드 상위권이다. CALVIN 4.547은 분할이 명시되지 않아 표준 calvin 블록이 아닌 별도 블록(calvin_split_unspecified)에 기록했다. T=3 변형, π0.5 기준선, 어블레이션은 별도 블록으로 분리했다. MemoryVLA, ST-π, CronusVLA, ContextVLA, UniMem 같은 다중 프레임·기억 VLA와 비교할 때, "새 모듈 없이 마스크만으로 시간 문맥을 넣는다"는 가장 가벼운 설계 극단을 대표한다.
