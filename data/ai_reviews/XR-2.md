# Scaling Bimanual Household Manipulation from 1,500 hours of Demonstrations to On-Policy Corrections (XR-2)

> **한 줄 요약**: 실로봇 텔레오퍼레이션 531.7시간(32,518 궤적)과 in-the-wild UMI 약 1,000시간으로 이루어진 1,500시간 양팔 가사 데이터셋을 공개하고, Qwen3-VL-4B + flow-matching action expert(총 5B) VLA **XR-2**를 전체 파라미터로 학습. 옷 개기에서 전문가 데이터 30h→120h에 성공률 34%→84%(160h 82%로 포화), 이후 실패 가중 DAgger 3라운드로 58%→93%.

- **arXiv**: 2609.03591v1 (2026-09-03, cs.RO)
- **소속**: PrimeBot Research Institute(Swancor), 북경대, Crobotia
- **데이터**: 논문 표기 프로젝트 페이지 huggingface.co/datasets/challenge-2026 (IROS 2026 Household Bimanual Manipulation Challenge)
- **모델 가중치 공개**: 논문에 명시 없음

---

## 1. 배경 및 동기

범용 양팔 조작 정책의 병목은 고품질 대규모 인간 시연 데이터의 부족이다. 데이터가 커질수록 질문은 "얼마나 모을까"에서 "어떤 데이터가 가치 있는가"로 바뀐다: 오프라인 전문가 시연은 성공 행동을 제공하고, on-policy 교정 데이터는 배포 시 방문 상태와 실패를 담는다. 이 두 데이터 원천의 스케일링을 한 모델에서 비교하는 것이 목적이다.

## 2. 문제 정의

(i) 1,500시간 양팔 가사 데이터로 VLA를 학습했을 때 전문가 데이터 양에 따른 성능 스케일링, (ii) 전문가 데이터 수익이 줄어든 뒤 DAgger 교정 데이터가 주는 추가 이득을 측정.

## 3. 방법

- **XR-2 구조**: Qwen3-VL-4B-Instruct VLM + 18블록 action DiT(hidden 1024, 8 heads, 4 KV group), 블록 i가 백본 i번째 층과 cross-attention하는 depth-aligned 설계, adaLN-zero 시간 조건, SwiGLU. 총 5B.
- **비동기 실행**: 이미 실행 중인 선행 행동 d개를 정답으로 고정(t=1)하고 뒤쪽만 노이즈·denoise하는 action-prefix conditioning. d는 최근 R회 추론 시간 평균. 5 Euler step.
- **Stage 1**: 전문가 데이터에 조건부 flow matching(t ~ Beta(1.0, 1.5)).
- **Stage 2 (DAgger)**: 정책 배포 중 사람이 개입한 구간을 교정 시연으로 자동 기록. DAgger:전문가 = 1:1(프레임이 아닌 **궤적 수** 기준)로 섞어 기술 분포 유지, 하위 과제 성공률 s_i가 낮을수록 더 많은 DAgger 예산을 주되 w_min=0.05 하한으로 망각 방지.

## 4. 데이터

- **X2W 로봇**: 7-DoF 팔 2개 + 1-DoF 그리퍼, 4-DoF 허리, 2-DoF 머리(22 관절) + 3륜 옴니 베이스. 89-D 고유감각, 25-D 행동, 30 Hz 동기 기록, 헤드 1 + 손목 2 카메라.
- **실로봇 데이터**: 32,518 궤적, 5,740만 프레임, 531.7시간, 4개 장면(접기 스테이션 14.6k, 세탁기 8.4k, 소파 6.1k, 빨래 바구니 3.4k), 11개 원자 기술, 프레임 단위 언어 주석. SOP 기반 VR 텔레오퍼레이션 + 자동 품질 검증 + VLM 주석 + 수동 검수.
- **UMI 데이터**: 200+ 가정, 100+ 수집자, 5,000종 의류, 약 1,000시간, 양손 동기 손목 영상(960², 30 Hz) + VI-SLAM 6-DoF 궤적 + 시각적으로 복원한 그리퍼 개폐, 2단계 언어 주석.

## 5. 구현 세부

- 배포: RTX 4090, 10 Hz 비동기 추론, 50×25 청크, temporal ensembling 후 30 Hz 전신 관절 명령, 1000 Hz 전신 모션 컨트롤러.
- DAgger 실험은 10개 하위 과제 18,695 전문가 궤적으로 학습한 체크포인트에서 시작, 라운드당 2.5 epoch 후학습.

## 6. 실험 설정

- 모든 테스트 환경에 약한 일반화(재료 크기·색, 로봇 초기 위치) 포함. 저자들은 일반화 조건 85%인 모델이 분포 내에서는 95%를 넘는다고 서술.
- 전문가 데이터 스케일링: 옷 개기, 10h~160h(8,000 궤적).
- DAgger: 옷 개기, 3라운드.
- 시행 횟수·다른 VLA와의 비교는 보고되지 않음.

## 7. 주요 결과

**전문가 데이터 스케일링(옷 개기, 본문 수치)**: 30h 34% → 120h 84% → 160h 82%. 120시간 이후 포화 — 남은 실패는 정책만 방문하는 상태에서 발생해 전문가 데이터로는 채울 수 없다는 해석.

**DAgger(옷 개기)**: 58% → 1라운드 74% → 2라운드 82% → 3라운드 **93%** (전문가 전용 대비 +35pt).

## 8. Related Work 상의 위치

- OXE, DROID, AgiBot World, RoboMIND 2.0 등 대규모 데이터셋 계열에 가사·양팔·모바일 + UMI 결합 데이터를 추가.
- 모델은 π0/π0.5, GR-3 계열의 VLM + flow-matching expert 구조를 따르며, GR-RL 등과 같이 배포 후 개선 데이터의 가치를 강조. DAgger의 실패 가중 예산 배분이 방법적 차별점.

## 9. 강점

1. 1,500시간 규모의 실로봇 + in-the-wild 양팔 가사 데이터 공개와 챌린지 운영으로 커뮤니티 기여가 큼.
2. 전문가 데이터 포화 → DAgger로 추가 향상이라는 상보적 스케일링 서사가 명확.
3. 궤적 수 기준 1:1 혼합과 실패 가중 폐형식 예산 배분이 단순하고 재현 가능.
4. 비동기 action-prefix 조건화, depth-aligned cross-attention 등 실배포 지향 설계.

## 10. 약점 및 한계

1. 평가가 옷 개기 단일 과제에 집중되고 시행 횟수·분산·통계가 보고되지 않는다. 대부분의 결과가 그림(Fig. 5)으로 제시되고 본문에는 일부 수치만 있다.
2. 다른 VLA(π0.5 등)와의 비교, 구조 요소 절제가 없어 XR-2 자체의 모델 기여를 판단하기 어렵다.
3. UMI 데이터가 XR-2 학습에 어떻게 쓰였는지(비중·효과)가 명시되지 않는다.
4. DAgger 실험 시작 체크포인트(58%)가 스케일링 실험의 최고치(84%)와 달라 두 실험 간 연결이 모호하다.
5. 표준 시뮬레이션 벤치마크 결과가 없어 트래커 내 다른 모델과 수치 비교 불가.

## 11. 재현 및 확장 아이디어

- 동일 데이터로 π0.5/GR00T 등을 학습해 XR-2 구조의 기여 분리.
- UMI 데이터 포함/제외 절제로 in-the-wild 데이터의 전이 효과 정량화.
- 여러 과제에서 DAgger 예산 배분(α, w_min) 민감도 분석, 실패 가중 vs 균등 배분 비교.
- 오프라인 RL/보상 모델과 DAgger 교정 데이터 결합.

## 12. 총평

이 논문의 핵심 산출물은 대규모 양팔 가사 데이터셋과 이를 활용하는 학습 레시피이며, 5B VLA XR-2를 직접 학습해 전문가 데이터 포화와 DAgger 교정의 상보성을 옷 개기에서 보여 준다. 데이터 기여는 크지만 모델 평가는 단일 과제·그림 중심·비교 부재로 얇아, 성능 주장은 제한적으로 받아들여야 한다.

**한 문장 요약**: 1,500시간 양팔 가사 데이터로 5B flow-matching VLA XR-2를 학습하고, 옷 개기에서 전문가 데이터 120시간 84%에서 포화된 성능을 실패 가중 DAgger 3라운드로 58%→93%까지 끌어올린 데이터 스케일링 연구.
