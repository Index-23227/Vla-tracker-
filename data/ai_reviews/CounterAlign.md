# CounterAlign: Counterfactual Supervision for Vision-Language-Action Models

> **한 줄 요약**: 성공한 전문가 시연만으로 "지시어를 바꿔 붙인" 반사실(counterfactual) 튜플을 만들어 명령-관측-행동 정합성을 평가하는 보상 모델(적대적 판별기 + nnPU 재라벨링 판별기)을 학습하고, 이 보상으로 π0.5를 오프라인 RL(IQL + advantage-weighted flow matching)로 후학습한다. LIBERO-PRO의 Pos/Task 교란에서 π0.5 BC 대비 큰 향상(예: Object-Pos 19 → 51, Goal-Task 17 → 46), TX-G2 실물 4개 과제 전부에서 π0.5를 상회.

- **arXiv**: 2608.21740v1 (2026-08-22, cs.RO)
- **소속**: Institute of Science Tokyo, AI Robot Association (AIRoA), RIKEN AIP, Tohoku University
- **프로젝트**: https://counteralign.airoa.io
- **백본**: π0.5 (전체 파라미터 파인튜닝, LoRA 미사용)

## 1. 배경 및 동기

VLA는 대부분 행동 복제(BC)로 학습되는데, BC는 "전문가가 한 행동"이라는 양성 신호만 준다. 같은 지시·관측에서 어떤 행동이 틀렸는지를 알려주는 음성 신호가 없으므로, 강한 VLA도 지시 패러프레이즈·물체 위치 변화·과제 변경에 쉽게 무너진다. RL은 교정 신호를 줄 수 있지만 온라인 RL은 보상 설계·롤아웃 비용이 크고, 오프라인 RL은 보상과 비전문가(실패) 궤적의 큐레이션이 필요하다. 저자들의 질문은 "데이터를 더 모으는 대신 시연 하나에서 더 많은 감독 신호를 뽑을 수 있는가"이다.

## 2. 문제 정의

- 데이터셋 D = {(l_i, o_t^i, a_{t:t+h}^i)} (지시, 관측, action chunk).
- 목표: 추가 환경 상호작용 없이 π(a_{t:t+h} | o_t, l)가 지시와 의미적으로 정합하는 행동을 내도록 학습.
- 핵심 관찰: 성공한 action chunk도 **부적절한 지시와 짝지으면** 실패 예시가 된다.

## 3. 방법: 두 판별기로 만든 명령-행동 정합 보상

- **적대적 판별기 D_adv**: GAIL처럼 전문가 action vs 현재 정책이 생성한 action을 구분. 단, 완전 오프라인(새 데이터 수집 없음). 미세한 행동 편차에 민감한 "저수준 충실도" 역할.
- **재라벨링 판별기 D_rel**: 행동이 지시를 따르는지를 거칠게(의미 수준) 평가.
  - *Instruction relabeling*: 원래 지시를 유사도 θ_min < S_l < θ_max 범위의 다른 지시로 교체 → 음성.
  - *Action relabeling*: action chunk를 유사도 범위 내 다른 chunk로 교체 → 음성.
  - *Joint relabeling*: 지시와 행동을 함께 교체(고유수용 상태 유사도 조건) → 음성이 보장되지 않으므로 **unlabeled**로 취급.
  - 손실: L_rel = λ·L_PN + (1−λ)·L_nnPU − α_H·H(D_rel). 엔트로피 정규화는 판별기 출력 포화(0/1 붕괴)를 막는다.
- 너무 비슷한(구분 불가) 또는 너무 다른(쉬운) 후보를 거르는 유사도 기반 샘플링으로 "의미적 near-miss"를 학습시키는 것이 핵심.

## 4. 정책 학습: 오프라인 RL

- 보상 r_t = (1−w)·log D_adv + w·log D_rel.
- IQL 기반: Q(clipped double-Q), V(expectile), EMA 타깃. 크리틱 학습에는 유사도가 높은 **near-positive 지시 재라벨링** 샘플을 추가(행동 재라벨링은 다음 관측이 없어 제외).
- 액터: flow-matching 정책은 log-likelihood 계산이 어려우므로 exp(β·(Q−V))로 가중한 flow-matching 손실(advantage-weighted flow matching)로 학습.
- 판별기 → 크리틱 → 액터를 반복 업데이트.

## 5. 구현 세부

- 정책 구조는 π0.5 BC와 동일(약 3.4B). 판별기·크리틱 추가로 총 학습 파라미터 약 12.7B.
- 두 판별기가 하나의 VLM 백본 공유(헤드 분리), Q/V도 백본 공유, 타깃 네트워크는 별도 백본.
- LIBERO: 15K step, batch 256, H200 8장, 약 28시간(BC는 H200 1장으로 가능하나 본 방법은 최소 5장 필요).
- TX-G2: 150K step, batch 64, H200 8장, 약 96시간. 추론은 RTX 5070.

## 6. 실험 설정

- **시뮬레이션**: LIBERO로 학습, LIBERO-PRO로 평가. 교란 4종 — Obj(외형), Pos(물체 위치), Sem(지시 패러프레이즈), Task(과제 변경). 셀당 100 trial.
- **기준선**: OpenVLA-OFT, VLA-Adapter, xVLA, π0.5(BC).
- **실물**: TX-G2(AGIBot G2 호환), 4개 과제(식기 옮기기 / 그릇 쌓기 / 옷 바구니 넣기 / 접시 랙 꽂기), 각 과제는 4–6개 primitive로 분해, 총 1,198 시연. 10 trial(8개 소교란 + 2개 분포 밖 교란), primitive 평균 성공률.
- **추가**: CALVIN ABC→D, 1,000 trial(부록).

## 7. 주요 결과

**Table 1 – LIBERO-PRO (%; 논문은 소수로 보고)**

| Suite | 설정 | π0.5 (BC) | CounterAlign |
|---|---|---|---|
| Spatial | Obj / Pos / Sem / Task | 99 / 53 / 97 / 55 | 98 / **60** / 97 / **63** |
| Object | Obj / Pos / Sem / Task | 89 / 19 / 95 / 10 | 80 / **51** / 99 / **26** |
| Goal | Obj / Pos / Sem / Task | 90 / 29 / 95 / 17 | 82 / **41** / 94 / **46** |
| LIBERO-10 | Obj / Pos / Sem / Task | 66 / 6 / 91 / 17 | 64 / **11** / 97 / **29** |

- Pos·Task에서 일관되게 크게 개선, Obj·Sem은 비슷하거나 일부 하락(Object-Obj 89 → 80, Goal-Obj 90 → 82).
- 저자 해석: Obj·Sem은 학습 궤적 재생만으로 풀리므로 BC를 과대평가하는 설정이고, Pos·Task가 진짜 의미 이해를 요구한다.

**Table 3 – TX-G2 실물 (%)**

| Method | Task1 | Task2 | Task3 | Task4 |
|---|---|---|---|---|
| VLA-Adapter | 0 | 0 | 0 | 0 |
| xVLA | 0 | 8 | 5 | 5 |
| π0.5 | 5 | 48 | 80 | 60 |
| **CounterAlign** | **20** | **53** | **93** | **85** |

**부록 Table 3 – CALVIN ABC→D**: 평균 길이 BC 3.93 → 4.03, 1~5연속 성공률 모두 소폭 향상(0.906→0.913, …, 0.682→0.703).

**Table 2 – 절제(LIBERO-PRO)**: 재라벨링 없는 기본 오프라인 RL만으로도 Pos/Task에서 BC 초과(예: Object-Pos 19 → 49). 판별기 재라벨링, 엔트로피 정규화, unlabeled 샘플, 크리틱 재라벨링이 대체로 기여하며, 액터 재라벨링은 일관된 이득이 없다(최종 모델은 액터 재라벨링 제외).

## 8. Related Work 상의 위치

- CAST, RoboReward처럼 대형 모델로 반사실 지시를 생성하는 방법과 달리 **데이터셋 내부 재조합**만 사용 → VLM의 공간 추론 한계와 비용을 회피.
- 대조학습 기반 정렬(Kwok et al.)의 in-batch false negative 문제를 유사도 필터링 + PU 학습으로 다룬다.
- 진행도 기반 보상(RewiND, VLAC 등)이나 성공 분류기와 달리, 과제 진척이 아니라 **지시-행동 의미 정합**을 보상화.
- CO-RFT, ARFM류 오프라인 RL 후학습과 같은 계열이지만 보상 원천이 반사실 재라벨링이라는 점이 차별점.

## 9. 강점

1. **추가 데이터 0**: 롤아웃, 보상 라벨, 실패 시연 없이 기존 성공 시연만으로 음성 감독을 합성.
2. **모호성의 정직한 처리**: joint relabel 샘플을 억지로 음성 처리하지 않고 nnPU로 unlabeled 취급.
3. **평가 설계에 대한 통찰**: LIBERO-PRO의 네 교란 중 무엇이 "진짜 의미 이해"를 측정하는지 논의하고, 개선이 그 축(Pos/Task)에 집중됨을 보임.
4. 실물 다중 과제, CALVIN 보조 실험, 구성요소별 절제까지 갖춤.

## 10. 약점 및 한계

1. **Obj 교란에서의 하락**: Object-Obj −9, Goal-Obj −8 등 일부 셀에서 BC보다 나빠지는데, 이를 "BC 과대평가 설정"으로만 설명한다. 평균이나 통계적 유의성은 보고하지 않음.
2. **막대한 학습 비용**: 학습 파라미터 3.4B → 12.7B, BC가 H200 1장이면 되는 것을 최소 5장 필요. 추가 파라미터의 대부분이 판별기·크리틱(별도 타깃 백본 포함)에서 온다.
3. **유사도 함수가 휴리스틱**: S_l, S_a, S_o, S_p 정의와 임계값이 본문에 없고 보충자료로 미뤄져, 다른 데이터셋으로의 이식성이 불명확.
4. **실물 평가 규모**: 과제당 10 trial, primitive 평균 성공률이라 분산이 크다. 기준선 OpenVLA-OFT는 GPU 메모리 부족으로 실물 비교에서 빠짐.
5. CALVIN 개선폭(+0.10)은 작다(저자도 인정).
6. 표준 LIBERO(비교란) 수치를 보고하지 않아 원래 분포 성능 유지 주장을 수치로 확인할 수 없다.

## 11. 재현 및 확장 아이디어

- 더 가벼운 판별기/크리틱(작은 VLM 또는 헤드만 학습)으로 비용-성능 곡선 측정.
- 유사도 임계값(θ_min, θ_max) 민감도 분석, 학습된 임베딩 기반 유사도로 대체.
- 반사실 재라벨링 보상을 온라인 RL(예: 시뮬레이터 PPO/GRPO)의 dense shaping 보상으로 사용.
- LIBERO-Plus, SimplerEnv 등 다른 강건성 벤치마크와 다른 백본(GR00T, OpenVLA-OFT)으로 일반화 검증.

## 12. 총평

"성공 시연에 틀린 지시를 붙이면 실패 예시가 된다"는 단순한 아이디어를 PU 학습과 오프라인 RL로 정교하게 엮어, BC가 제공하지 못하는 음성 감독을 추가 수집 없이 얻는다. 위치·과제 교란에서의 개선은 설득력 있지만, 약 4배로 늘어나는 학습 파라미터와 일부 외형 교란 셀의 하락, 휴리스틱 유사도 설계는 실용화 전에 검증이 필요하다.

**한 문장 요약**: 데이터셋 내 지시/행동 재조합으로 명령-행동 정합 보상을 학습해 π0.5를 오프라인 RL로 후학습한 방법 — LIBERO-PRO Pos/Task와 TX-G2 실물에서 BC를 꾸준히 이기지만, 비용이 크고 외형 교란에서는 일부 손해가 있다.
