# NeuroSymbolic-Procedural-VLA — Towards Neuro-Symbolic Procedural Reasoning for Long-Horizon VLA Manipulation

- arXiv: 2609.05369 (v1 2026-09-04)
- 소속: Fraunhofer IPK, Technische Universität Berlin (Vivek Chavan, Yahuan Shi, Oliver Heimann, Kevin Haninger, Jörg Krüger)
- 참고: 논문은 방법에 별도 이름을 붙이지 않았으며, 트래커 이름은 서술적 명칭이다.

## 1. 한 줄 요약

작업 그래프와 다중모달 절차 기억으로 "다음에 무엇을 할지"를 정하고, 미세조정된 π0.5가 "어떻게 할지"를 실행하는 신경-기호 파이프라인을 제안하는 짧은(약 4쪽) 초기 연구다. 실제로 실험된 부분은 **희소 절차 saliency(pseudo-gaze)로 유도한 π0.5 미세조정**이며, 시각 프롬프트와 어텐션 정규화 두 방식 모두 수술 도구 처리 과제에서 25/25를 기록했다.

## 2. 문제 설정

VLA는 짧은 기술은 잘 수행하지만, 지속적 진행 상태, 의존성 인지, 조건 분기, 신뢰할 수 있는 객체·목적지 그라운딩이 필요한 긴 절차에서는 취약하다. 특히 사람이나 다른 에이전트가 일부 단계를 수행하는 협업 상황에서는 외부 사건을 인식해 절차를 갱신해야 한다.

## 3. 핵심 아이디어

observe–ground–remember–choose–execute–verify 루프. 작업 그래프 G = (V, E)의 각 노드는 지시문, 실행 주체(로봇/사람/다른 에이전트), 시각적으로 확인 가능한 사전·성공·실패 조건, 상태를 갖는다. 추가 전용(append-only) 이벤트 기억이 결정·관측 전이·시각 증거를 기록하고, 로봇 노드가 준비되면 해당 하위 목표를 VLA에 전달한다. 저층 그라운딩은 사람 시연에서 얻은 희소 saliency로 보강한다.

## 4. 아키텍처

- 상위: 작업 그래프 + 이벤트 기억 + VLM 추론기(선택·검증), 고정 전역 카메라와 손목 카메라로 상태 전이 검증.
- 하위 실행기: π0.5, 입력은 기저 시점·손목 시점·로봇 상태·하위 목표 지시문.
- Saliency: 하위 목표당 대표 궤적 하나에 시간 변화 점 g_t(pseudo-gaze)를 주석하고, DINOv2 특징으로 반복 시연에 전이한 뒤 피라미드 Lucas–Kanade 광류로 안정화.

## 5. 학습과 추론

두 가지 정책 인터페이스를 학습한다.
- Prompt-as-input: RGB에 자홍색 링 R(I_t, g_t)을 그려 넣고 미세조정·추론.
- Prompt-as-supervision: g_t를 토큰 단위 목표 분포 G_t로 바꿔 행동 조건 어텐션 S_t와 정렬, L = L_act + λ·D_KL(G_t‖S_t). 추론 시에는 깨끗한 이미지만 입력.
학습 데이터는 7단계 수술 도구 처리 절차의 원격조작 에피소드 231개.

## 6. 주요 결과 (Table 1, 실제 로봇)

5개 하위 목표 × 조건별 5회 = 조건당 25회, 총 75회.

| 조건 | RGB 단서 | 목적지 텍스트 | 전체 | 컨테이너 |
|---|---|---|---|---|
| Prompt-finetuned (단서 제거) | 없음 | highlighted | 20/25 | 5/10 |

프롬프트로 학습한 체크포인트에서 단서를 빼면 모호한 컨테이너 라우팅이 10/10 → 5/10으로 떨어지며, 실패 5건은 모두 잘못된 목적지 배치다.

## 7. 정성 분석

어텐션 정규화 정책은 과제 관련 영역에 어텐션이 집중되는 히트맵을 보인다(Fig. 2). 반면 시각 프롬프트는 행동은 개선하지만 집계 어텐션 변화는 뚜렷하지 않아, "행동 유용성"과 "가시적 어텐션 정렬"이 서로 다른 성질임을 시사한다. 기저 시점 saliency만으로 충분했는데, 전역 시점이 공간 모호성을 해소하고 손목 시점은 근거리 제어를 담당하기 때문으로 해석한다.

## 8. 어블레이션

별도 어블레이션 표는 없다. Table 1의 "단서 제거" 조건이 사실상 saliency 제거 어블레이션 역할을 한다. 두 유도 방식은 점수가 천장(25/25)에 도달해 서로 구별되지 않는다.

## 9. 설계 해석

"무엇을(기호 구조)"과 "어떻게(학습된 제어)"를 분리하고, 그 사이를 지각 기반 검증으로 연결하는 전형적 계층형 구조다. 흥미로운 점은 같은 saliency 신호를 입력 프롬프트(배포 시 오버레이 필요)와 학습 감독(배포 시 오버레이 불필요) 두 방식으로 쓸 수 있게 한 공통 인터페이스다. 향후 사람 1인칭 시선을 교차 시점 전이로 pseudo-gaze 대신 쓸 수 있다는 설계 여지를 남긴다.

## 10. 강점

- 기호적 절차 구조와 VLA 제어를 결합하는 명확한 문제 정의와 협업(사람 수행 단계) 고려.
- 명시적 프롬프트 vs 내재화된 어텐션 정규화라는 두 saliency 활용 방식을 동일 조건에서 비교.
- 실패 원인(잘못된 목적지)이 구체적으로 보고되어 saliency의 역할이 분명하다.

## 11. 한계

- 제목과 달리 작업 그래프·기억·검증을 포함한 **전체 파이프라인은 평가되지 않았다**(저자가 향후 과제로 명시).
- 평가가 조건당 25회, 단일 과제 도메인이며 두 유도 방식 모두 천장에 도달해 비교력이 낮다.
- 일반 미세조정(단서 없이 학습·평가) 기준선이 없고, 시각 프롬프트 없이 학습한 π0.5와의 비교가 부재하다.
- 새로운 좌표로의 임의 재지정이나 보지 못한 장면 일반화는 검증되지 않았다(저자 명시).
- 워크숍 수준의 짧은 보고로 하이퍼파라미터(λ 등) 세부가 없다.

## 12. VLA-Tracker 관점 평가

π0.5를 saliency 유도 방식(시각 프롬프트, KL 어텐션 정규화)으로 직접 미세조정하고 실제 로봇에서 정량 결과를 보고했으므로 수록 기준(자체 학습 정책 + 정량 결과)을 충족한다. 다만 결과가 성공 횟수(x/25, x/10)로만 제시되어 백분율로 환산하지 않고 `real_world_instrument_handling_successes` 별도 블록에 원래 표기대로 기록했으며, 순위용 `real_world` 블록은 두지 않았다. 핵심 기여인 신경-기호 파이프라인은 아직 미검증이므로 후속 버전에서 종단 간 결과가 나오면 갱신이 필요하다.
