# RoleSub — Role-Conditioned Sub-Token Routing for Efficient Vision-Language-Action Policies

- arXiv: 2608.18410 (2026-08-19)
- 소속: Futurewei Technologies (Wei Jiang, Wei Wang)

## 1. 한 줄 요약

RoleSub는 시각 토큰을 더 버리는 대신 **남겨 둔 토큰의 value 벡터 폭을 줄이는** 서브토큰 라우팅을 VLA에 맞게 확장한 방법으로, 직교 회전 공간에서 value를 16개 그룹으로 나누고 토큰 상태·학습된 잠재 역할·언어 맥락으로 유지할 그룹을 고른다. OpenVLA-OFT-7B에 LoRA와 함께 학습해 LIBERO 36개 동일 KV 예산 설정 중 33개에서 학습된 토큰 전용 프루닝 대조군을 앞서고, 시각+언어 결합 압축으로 전체 prefix KV를 원본의 9.2–11.3%까지 줄인다.

## 2. 문제 설정

VLA는 매 제어 스텝마다 시각 토큰이 지배하는 긴 멀티모달 prefix를 처리한다. 기존 가속(VLA-ADP, VLA-Pruner, FastV, VisionZip 등)은 토큰 단위로 제거하므로 예산이 작아질수록 토큰 하나를 버릴 때 그 토큰의 위치·기하·조작 정보가 통째로 사라진다. 폐루프 제어에서는 이 오차가 이후 관측을 바꾸며 궤적 전체로 전파된다. 저자들의 이전 연구(Sub-token routing, LLM/VLM용)를 VLA에 그대로 적용하면 균일 S=4, K=1 설정에서 LIBERO-Spatial 43.8%에 그쳐, "얼마나 남기느냐"뿐 아니라 "표현 안에서 용량을 어떻게 배분하느냐"가 중요하다는 것이 출발점이다.

## 3. 핵심 아이디어

토큰 수(몇 개의 상태를 남길지)와 value 폭(각 상태에 얼마만큼의 정보를 남길지)을 **독립적인 두 압축 축**으로 본다. query·key는 그대로 두고 value 경로만 압축한다. 어느 차원이 의미·기하·제어에 대응하는지 미리 알 수 없으므로, 고정 분해 대신 제어 목적으로부터 라우팅 구조를 학습하도록 설계했다.

## 4. 방법

- **토큰 수준 축소**: VLA-ADP 구현의 QK 기반 선택을 임베딩 층에서 적용해 512개 시각 토큰 중 8/16/32개만 남긴다(두 카메라에 균등 배분).
- **직교 value 공간 분해**: 층마다 랜덤 Stiefel 행렬로 초기화 후 고정한 직교 행렬 R로 v를 회전(z = Rᵀv)하고 d_v=4096을 S=16개 그룹(256차원)으로 나눈다. 모든 그룹을 유지하면 원래 v가 복원되므로 정보 손실은 그룹 선택에서만 발생한다.
- **잠재 역할 표현**: 층별 경량 추정기가 softmax로 C=6차원 소프트 역할 벡터 a를 만든다. 의미 레이블을 가정하지 않고 행동 손실로만 학습된다.
- **역할 조건 라우팅**: 그룹 점수 γ = γ_token + 0.1·W_role a + 0.1·f_lang(pool(언어 은닉)) 로 Top-K 그룹을 고르며, 이산 선택은 straight-through 추정기로 역전파한다.
- **토큰 유형별 예산**: 유형 m마다 평균 K_m을 고정하되, 역할 기반 할당기가 같은 유형 내에서 중요한 토큰에 더 많은 그룹을 배분한다.

## 5. 학습

사전학습 백본은 고정하고 LoRA(rank 32, scaling 16, 모든 선형층, 약 110.8M), 라우팅 헤드(약 4.20M), 역할 추정기(약 0.55M)를 8-액션 청크 L1 손실로 공동 학습한다. 직교 행렬은 고정이라 학습 파라미터가 없다. 데이터는 no-op 필터링된 LIBERO RLDS(Spatial 432, Object 454, Goal 428, LIBERO-10 379 에피소드), 이미지 증강 사용, AdamW lr 2×10⁻⁴, 유효 배치 8. 즉 가중치(LoRA)가 실제로 갱신되는 자체 학습 정책이다.

## 6. 실험 설정과 기준선

평가는 네 LIBERO 스위트, 태스크당 50 trial, 시뮬레이터 설정·시드 고정. 기준선은 (i) 공식 OpenVLA-OFT 스위트별 체크포인트(비압축), (ii) 학습 없는 토큰 프루닝, (iii) 같은 LoRA 절차로 학습하되 동일 시각 KV 예산에 맞춰 토큰만 줄인 **학습된 토큰 전용 대조군**(r_matched = r_vis(S+K_vis)/2S), (iv) R=I, 역할 항 제거, 균일 K인 **plain 서브토큰 라우팅**. 학습 없는 프루닝은 K_vis=1에 대응하는 12개 운용점 중 10개에서 0%였고(최대 예산에서 Goal 29.0, Spatial 9.2만 비영), 그래서 (iii)을 주 비교 대상으로 삼는다.

## 9. 언어 value 압축과 결합 압축 (Table 3–5)

언어 토큰은 제거에 매우 민감하다(Goal에서 토큰 53% 유지 시 성공률 약 40%). 반면 모든 언어 토큰을 남기고 value만 줄이면 K_lang=1(그룹 1/16, 언어 KV 53.13%)에서도 Goal 98.0 / LIBERO-10 94.8 / Object 98.4 / Spatial 98.0으로 밀집 정책 수준이다. 시각 K_vis=1과 언어 K_lang=1을 결합하면 전체 KV가 9.2%/9.9%/11.3%(8/16/32 토큰)로 줄고, Object·Spatial은 시각 전용 대비 −1.4~+0.7%p, Goal은 −0.8~−2.9%p에 그친다. 그러나 LIBERO-10은 −10.0~−11.2%p로 크게 떨어진다(32토큰 결합 77.6 vs 시각 전용 88.4). Table 5에서 언어 예산을 K_lang=1→8→16으로 늘리면 LIBERO-10이 8토큰 64.2→68.4→83.6, 32토큰 77.6→84.8→87.6으로 회복되어, 시각과 언어 예산이 서로 결합되어 있음을 보여 준다.

## 10. 강점

- 토큰 수와 value 폭을 분리한 압축 축을 VLA에서 체계적으로 검증했고, 동일 LoRA 학습을 거친 토큰 전용 대조군과 동일 KV 예산으로 비교해 "적응 학습 효과"와 "라우팅 효과"를 분리했다.
- plain 서브토큰 라우팅 대비 개선이 공격적 예산에서 가장 커서, 직교 공간·역할 조건·유형별 예산의 기여를 보여 준다.
- 언어는 토큰 위치가 중요하고 value 폭은 대부분 중복이라는 비대칭 관찰은 향후 VLA KV 설계에 유용하다.

## 11. 한계

(1) 논문 스스로 밝히듯 KV 저장량만 줄였을 뿐 **end-to-end 지연 시간은 측정하지 않았다**. 실제 속도 이득은 희소 value 연산 커널 구현에 달려 있다. (2) 백본은 OpenVLA-OFT-7B 하나, 벤치마크는 LIBERO 하나뿐이며 실로봇 실험이 없다. (3) 스위트별로 학습·평가한 것으로 보이며 다중 스위트 단일 모델 평가가 없다. (4) 시각·언어 예산을 따로 정하므로 장기 과제에서 결합 압축 시 큰 손실이 난다(교차 모달 공동 할당은 미래 과제). (5) 학습된 잠재 역할이 해석 가능한 의미를 갖는다는 보장이 없다. (6) 본문과 표 사이 수치 불일치(8토큰 Goal 95.2 vs 93.5)가 있다. (7) 코드 공개 언급이 없다.

## 12. VLA-Tracker 관점 평가

제목과 목적은 추론 효율화지만, RoleSub는 고정된 정책 위의 학습 없는 런타임 기법이 아니라 **LoRA 어댑터·라우터·역할 추정기를 행동 손실로 공동 학습**해 압축된 정책 가중치를 새로 만든다. 따라서 추적 대상에 포함한다. 행동 헤드는 OpenVLA-OFT의 병렬 디코딩 L1 회귀이므로 `action_head_category: regression`. 대표 점수는 논문이 주 설정으로 반복 사용하는 시각 토큰 32/512, K_vis=1 행(Goal 97.2, LIBERO-10 88.4, Object 96.4, Spatial 97.8)이며, 논문이 평균을 보고하지 않으므로 `libero_avg`는 선언하지 않았다. 8/16토큰 설정, 토큰 전용·plain 기준선, 결합 압축, 언어 전용, 밀집 참조는 형제 블록으로 분리했다.
