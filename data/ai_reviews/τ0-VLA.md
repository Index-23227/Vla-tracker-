# τ0-VLA — a Hierarchical Robot Foundation Model with World-Model-Guided Test-Time Computation

- arXiv: 2608.16885 (2026-08-17)
- 소속: Agibot Finch, Shanghai Innovation Institute, The Chinese University of Hong Kong (교신저자 Jianlan Luo)
- 프로젝트 페이지: https://tau0-vla.github.io/

## 1. 한 줄 요약

τ0-VLA는 40,115시간의 이종 실세계 로봇 데이터로 학습한 범용 저수준 VLA(Qwen3.5-2B + MoT 흐름 매칭 액션 전문가) 위에, 실행 메모리를 갖춘 고수준 정책을 얹은 계층형 시스템이다. 고수준 정책은 확신이 낮을 때만 "제안 → 월드 모델로 결과 상상 → 가치 모델로 채점 → 빔 탐색 → 반성적 확정" 절차로 서브태스크 선택에 테스트 타임 연산을 추가로 쓴다. 실물 장기 과제 4종 평균 성공률을 27.50%(직접 실행)에서 45.00%(계층형, Plan Once)로 끌어올렸고, TTC를 켜면 Book Organization 성공이 6/10에서 9/10으로 오른다.

## 2. 문제 설정

방 청소, 요리, 음료 제조처럼 수 분에서 수십 분 걸리는 장기 조작은 정밀한 모터 제어만으로 풀리지 않는다. 잘못된 서브태스크를 고르면 완벽하게 실행해도 실패한다. 기존 계층형 VLA는 대개 한 번의 순전파로 다음 서브태스크를 결정해 대안을 비교하거나 물리적 결과를 미리 따져 보지 않는다. 그러면 오류는 실행으로 환경이 바뀐 뒤에야 드러나고, 재계획은 대응은 해도 잘못된 실행의 비용을 되돌리지 못한다. 논문은 병목이 계층 인터페이스의 유무가 아니라 "다음 서브태스크를 생성하는 추론 절차"라고 보고, 이를 연산량을 늘릴수록 좋아지는 추론 문제로 재정식화한다.

## 3. 핵심 아이디어

- **서브태스크 단위 테스트 타임 연산**: 액션 수준 탐색은 국소적 결과만 보여 주고, 언어만의 추론은 물리적 근거가 없다. 서브태스크는 추가 연산을 정당화할 만큼 드물게 일어나면서도 환경 변화를 구분할 만큼 시간적으로 길어 탐색 단위로 적합하다.
- **적응형 라우팅**: 제안 모델의 토큰 확신도 통계로 g_t ∈ {0,1}을 계산해, 확신이 높으면 직접 제안(fast route)을 쓰고 낮을 때만 TTC를 호출한다. 임계값은 과제별로 held-out 데이터에서 보정한다.
- **자기 교정형 실행 메모리**: 시연에서 파생한 메모리를 뒤처짐/앞서감/진행 오표현 형태로 교란하고, 관측과 맞는 올바른 메모리와 서브태스크를 복원하도록 학습한다. 추가 사람 라벨이 필요 없다.

## 4. 아키텍처

**고수준 정책 µ** (네 개 모듈)
- 제안 모델 P: 과제 지시 ℓ, 이전 메모리 M_{t-1}, 직전 서브태스크 z*_{t-1}, 다시점 관측 o_t를 받아 메모리를 갱신하고 서브태스크를 제안한다(`<think>`, `<memory>` 필드 포함). Qwen3.5-9B에서 출발한 로봇 사전학습 VLM을 파인튜닝.
- 월드 모델 W: 헤드 카메라 이미지 한 장과 후보 서브태스크를 받아 해당 서브태스크 완료 시점의 이미지를 예측한다. Step1X-Edit 초기화.
- 가치 모델 V: 전역 지시, 후보, 예측 이미지로 5단계 순서형 품질(clearly wrong ~ clearly correct)을 고르는 객관식 VQA이며 [0.05, 0.95] 스칼라로 매핑된다.
- 반성 모델 F: 남은 빔 요약과 관측 정렬 컨텍스트를 보고 최종 서브태스크를 생성한다. 후보 집합에 제한되지 않는다.

**저수준 정책 π_θ**
- Qwen3.5-2B VLM 백본 + Mixture-of-Transformers 액션 전문가. 각 full-attention 층에서 액션 토큰과 백본 토큰이 공동 어텐션을 하되 파라미터는 분리된 스트림으로 처리한다.
- 엔드이펙터, 팔 관절, 그리퍼, 허리, 모바일 베이스를 포괄하는 **통합 40차원 상태/행동 공간**. 샘플별 마스크로 유효 채널을 고르고, 텍스트 제어 메타데이터 η로 체화(embodiment)와 제어 모드를 지정한다. 체화별 출력 헤드가 없다.
- **마스크드 흐름 매칭**: π0의 선형 가우시안 경로를 역시간 재매개변수화해 쓰고 비활성 채널은 경로와 손실 모두에서 마스킹한다. τ = 0.001 + 0.999x, x ∼ Beta(1.5, 1)이며 샘플별 정규화 손실은 100으로 상한을 둔다. 액션 호라이즌 H = 30, Euler 10스텝.

## 5. 테스트 타임 탐색 절차

깊이 d = 1..D마다 남아 있는 각 가지에 대해 제안 모델을 N번 독립 샘플링하고, 월드 모델로 종단 이미지를 상상한 뒤 가치 모델 점수를 누적한다. 모든 자식을 누적 점수로 전역 정렬해 상위 B개만 남기고(Top-B), 남은 가지의 예측 이미지와 가지별 메모리를 다음 확장의 문맥으로 쓴다. 탐색 내부에서 만든 메모리는 가지 로컬이라 실제 메모리 M_t를 덮어쓰지 않는다. 깊이 D까지 확장한 뒤 반성 모델이 최종 결정을 내린다. 연산 예산은 분기 수 N, 빔 폭 B, 깊이 D로 조절된다. 배포 시에는 고수준과 저수준을 비동기 파이프라인으로 돌려, 고수준은 약 1초마다 캐시된 서브태스크를 갱신하고 저수준은 약 30 Hz 제어 주기로 캐시를 읽기만 한다.

## 6. 학습 파이프라인

**데이터**: 저수준 코퍼스는 내부 수집 약 23.4K시간(AGIBOT G1 21.9K, G2 585, ARX AC One 578, Franka 347시간)과 공개 데이터 약 16.7K시간(오픈소스 UMI 9.25K시간 포함)으로 구성되며, 여기에 멀티모달 지시 따르기/그라운딩/공간·깊이 추론 데이터를 섞는다. 고수준 데이터는 Gemma4-31B-it로 `<think>`/`<memory>`를 사전 라벨링하고 ffmpeg으로 3시점 키프레임을 추출해 VQA 형태로 조립한다. 필터링 후 40.4M(88.26%) 샘플을 남긴다.

**저수준 3단계**: (1) 지식 격리(KI) 공동 학습: 액션 손실 그래디언트를 백본 인터페이스에서 차단. (2) KI를 풀고 end-to-end 공동 학습. (3) 배포 과제별 소량 시연으로 태스크 특화 파인튜닝.

**고수준**: 제안/가치/반성 모델은 같은 로봇 사전학습 VLM 체크포인트에서 각각 파인튜닝한다. 월드 모델은 서브태스크 구간의 시작/끝 헤드 카메라 프레임 쌍으로 학습한다. P와 W를 번갈아 적용한 오프라인 상상 롤아웃을 만들어 가치 모델(정답 다음 단계 대비 등급)과 반성 모델(정답 서브태스크를 자기회귀 타깃으로)을 학습한다.

## 9. 테스트 타임 연산 실험

- **폐루프 (Table III)**: 저수준 정책을 고정하고 TTC만 켠 결과, Make Milk Tea 5/10 → 7/10 (Prog 91.92 → 95.38), Book Organization 6/10 → 9/10 (66.67 → 93.33), Clean Room 5/10 → 7/10 (94.80 → 97.60)로 모든 과제에서 오른다. 고정된 실행 계획이 없는 Book Organization에서 이득이 가장 크다.
- **개루프 서브태스크 예측**: 서브태스크 경계 샘플에서 GPT-5.4를 의미 판정자(equivalent/adjacent/wrong)로 써서 정확도를 잰다. 본문에서 수치로 보고된 OOD Book Organization(학습에 없는 초기 배열)에서는 TTC 74.0%, Plan Once 50.0%, Best-of-N(같은 월드/가치 모델, 1스텝 선택) 57.5%다. 나머지 설정의 막대 값은 Fig. 4에만 있어 YAML에는 넣지 않았다.
- **연산량-정확도**: Fig. 5에서 PFLOPs/sample을 늘리면 정확도가 빠르게 올랐다가 포화하며, 저자들은 포화 지수 함수로 적합한다. 중간 예산에서 연산 대비 효율이 가장 좋다는 결론이다.

## 10. 관련 연구 대비 위치

- π0.5 등 기존 계층형 정책처럼 고수준 VLM과 저수준 VLA를 언어 서브태스크로 잇는 계층 구조를 따르지만, 고수준 결정에 추가 연산을 쓸 수 있게 만든 점이 다르다.
- 서브골 이미지를 생성해 저수준 실행을 조건화하는 기존 월드 모델 계층형 시스템과 달리, τ0-VLA의 시각 예측은 확정 **이전에** 여러 후보를 비교하는 데 쓰인다. 즉 "어떻게 실행할지"가 아니라 "무엇을 실행할지"에 개입한다.
- 장면 그래프 서브골 탐색이나 이산 계획 탐색과 비교하면, 열린 어휘의 언어 서브태스크를 탐색하고 예측된 종단 이미지로 각 후보를 평가한다는 점이 차별점이다.

## 11. 강점과 한계

**강점**
- 4만 시간 규모의 실세계 데이터, 40차원 통합 행동 공간, 3개 로봇 플랫폼(AGIBOT G1, ARX AC One, 양팔 Franka)에 걸친 실물 평가로 범용 저수준 정책의 실용성을 보인다.
- 최대 12분짜리 장기 과제에서 메모리 기반 계층화의 효과(Tomato & Egg Stir Fry 0/10 → 4/10)를 구체적인 실패 원인과 함께 제시한다.
- TTC 이득을 개루프 예측 정확도와 폐루프 성공률 양쪽에서 확인한다.

**한계**
- 모든 실물 결과가 과제당 10회라 1회 차이가 10%p다. 신뢰구간이나 통계 검정이 없다.
- 과제 4종 비교(Table I)의 계층형 행은 빔 탐색을 끈 Plan Once이고, TTC는 3개 과제(Table III)에서만 따로 평가되어 전체 시스템의 최종 성능이 한 표에 정리되어 있지 않다.
- Stage 3에서 과제별 파인튜닝을 하므로 제로샷 범용성이 아니라 "사전학습 + 과제 적응" 조건의 결과다. 외부 기준선(π0.5, GR00T N1.7, LingBot-VLA)이 같은 과제 데이터로 어떻게 적응되었는지는 본문만으로 분명하지 않다.
- 개루프 정확도는 LLM 판정자에 의존하고, Fig. 4의 과제별 값 대부분은 그림으로만 제공된다.
- LIBERO, SimplerEnv 같은 표준 시뮬레이션 벤치마크 결과가 없어 다른 모델과 정량 비교가 어렵다. 파라미터 총량, 추론 지연, 코드와 가중치 공개 여부도 명시되지 않았다.
- 메모리 어블레이션은 프로토콜만 기술되어 있고 수치 결과가 표로 제시되지 않는다.

## 12. VLA-Tracker 관점 평가

제목의 "Test-Time Computation"만 보면 동결된 정책 위의 추론 래퍼로 오인할 수 있지만, τ0-VLA는 저수준 VLA를 Qwen3.5-2B에서 3단계로 직접 학습하고(4만 시간 로봇 데이터), 고수준 제안/가치/반성 모델과 월드 모델도 모두 자체 파인튜닝한다. 자체 정책 가중치와 정량 결과가 있으므로 추적 대상에 포함한다. 저수준 행동 생성은 MoT 액션 전문가의 마스크드 조건부 흐름 매칭이므로 `action_head_category: flow_matching`으로 분류했다. 헤드라인 `real_world` 블록은 Table I의 계층형(Plan Once) 행이며, 직접 실행 변형, TTC(Table III), 체화 간 직접 실행(Table II), 각 기준선, 개루프 OOD 예측 정확도는 모두 조건별 형제 블록으로 분리했다. 성공률은 논문 표기(x/10)를 그대로 문자열로 옮겼고, 평균 SR(45.00, 27.50 등)은 논문이 직접 보고한 값만 수치로 넣었다.
