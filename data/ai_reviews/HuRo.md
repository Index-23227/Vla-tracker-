# HuRo — Robotizing Human Videos for Scalable VLA Pretraining

**arXiv**: 2609.10706 · **기관**: RLWRLD, Yonsei University · **날짜**: 2026-09-09

## 1. 한 줄 요약
이질적인 1인칭 인간 영상 5종을 "로봇화"(사람 팔 제거 + 로봇 오버레이 + 손 동작 리타게팅)해 약 63만 에피소드·1.42억 프레임의 HuRo 데이터셋을 만들고, 이를 GR00T-N1.6-3B 구조 VLA 사전학습에 사용해 ALLEX 실로봇 4개 과제의 전체 완수율을 51.5%→80.3%로 끌어올린 연구.

## 2. 문제 설정
- 실로봇 데이터는 비싸고, 인간 영상은 풍부하지만 관측(사람 손/팔)과 행동(사람 손 궤적) 양쪽에 체화 격차가 있다.
- 기존 관측·행동 동시 로봇화(Phantom, DexUMI, MimicDreamer 등)는 주로 과제 정렬(task-matched) 설정에서만 검증되었고, H2R·Masquerade 같은 시각 로봇화는 표현 학습/보조 목표에만 쓰였다.
- 핵심 질문: 이질적인 대규모 인간 영상이 "로봇 정렬 관측–행동 쌍"의 확장 가능한 공급원이 될 수 있는가?

## 3. 핵심 아이디어
- 소스별로 주석 수준이 다른 영상(원시 RGB ~ 카메라·손 포즈 제공)을 받아 **빠진 중간 신호만 추정**해 공통 로봇 관측–행동 포맷으로 변환하는 파이프라인.
- 행동: HaWoR 손 포즈 + DROID-SLAM/MoGe-2/GeoCalib 카메라 궤적 → PyRoKi 2단계 IK로 청크 단위 월드→로봇베이스 정렬(3D 이동+yaw)과 관절 궤적 최적화 → a_t = s_{t+1}.
- 관측: SAM2(+Detectron2 프롬프트)로 팔 분할, ProPainter 인페인팅, Isaac Sim으로 리타게팅된 로봇 렌더링·합성. 같은 정렬 변환을 카메라에 적용해 시점 일관성 유지.
- 언어: 손목 궤적을 그린 프레임을 Qwen3.5에 넣어 청크 단위 지시문 생성 + 검증 패스.

## 4. 아키텍처
- 정책은 GR00T-N1.6-3B 구조. VLM 백본은 공식 체크포인트로 초기화, DiT 액션 헤드는 처음부터 학습.
- 행동 공간: 양손 손목의 상대 포즈(3D 이동 + 6D 회전, 카메라 프레임 기준) + 손 관절 절대 목표, 청크 길이 H=40.
- 대상 로봇 ALLEX: 7-DoF 팔 2개, 15-DoF 손 2개, 2-DoF 목, 2-DoF 허리(평가 시 목·허리 고정).

## 5. 학습 목표
- Flow matching 목표로 로봇화 관측 + 리타게팅 행동을 end-to-end 학습(시각 인코더도 공동 미세조정).
- 인간 영상에는 로봇 행동이 없으므로 리타게팅된 상태 궤적의 다음 상태를 행동 라벨로 사용.

## 6. 학습 절차
- 사전학습: 80k step, 글로벌 배치 2048, AdamW lr 1e-4, wd 1e-5, 상수 스케줄 + 선형 워밍업.
- 다운스트림: 30k step, 배치 128, 코사인 lr 1e-4. 과제당 시연 16~43개.
- 데이터 구성(프레임 기준): EgoDex 55.5%, EgoVerse 26.5%, Ego4D 10.4%, Ego10K 6.0%, EPIC-Kitchens 1.7%, 총 142.2M 프레임(1,316.8시간). 스케일링 실험은 0/10/50/100% 부분집합(소스 비율 유지).

## 8. 어블레이션
- **시각 로봇화**: no-overlay는 ID 89.4로 비슷하지만 OOD 55.7로 급락하며, 10% PT(OOD 59.5)보다도 낮다.
- **행동 감독**: Diverse Pick-and-Place에서 Visual+Action 사전학습이 ID 61.1 / OOD 50.0 달성(No PT, Visual-Only 수치는 그림으로만 제시).
- **Masquerade식 비교(Table 3, EPIC 2.4M 프레임)**: No PT 63.9/25.0 → Fixed-EEF 75.0/50.0 → +Hand 80.6/61.1 → HuRo-EEF+Hand 86.1/63.9. 카메라 움직임 인지 로봇화가 유효.
- **인간 도메인 데이터(Table 4, OOD)**: Cup Stacking/Cup-Noodle에서 Human-HRDT 5.6/37.5, Human-VITRA 0.0/9.7, HuRo 70.8/66.7.
- **다중 소스 vs 단일 소스**: Mixed 50%(71.1M 프레임)가 EgoDex-only(78.9M)보다 우수(78.2/69.8 vs 63.9/54.2).
- **비디오 생성 기반(I2V+IDM)** 대비 모든 예산에서 우위(수치는 그림 위주).

## 9. 교차 체화 확장
- OpenArm + XHand1 과일 집기(Table 7): HuRo PT 전체 72.9로 최고(No PT 49.0, Human-HRDT 65.6, Human-VITRA 22.9, visual-only 43.8, no-overlay 62.5). ID는 Human-HRDT(75.0)가 약간 높고 OOD는 HuRo(75.0)가 우위.
- ALLEX+OpenArm 공동 로봇화 사전학습: 86.1/63.9 → 91.7/77.8.
- 체화별 재계산은 리타게팅·오버레이만 필요해 전체 처리비용의 10.6%(EPIC), 5.5%(Ego4D).

## 10. 파이프라인 품질·비용
- RTX 5090 1장 기준 원본 길이의 약 8~10배 처리 시간(주석 단계가 대부분).
- 카메라 회전 오차 중앙값 0.218°, 손 키포인트 오차 20.4 mm, IK 손끝 잔차 21.2 mm, 관절 한계 위반 없음 62.5%, 비파지 자기접촉 없음 55.2%, 인물 픽셀 93.3% 감소.

## 11. 강점과 한계
**강점**
- 데이터 스케일링 곡선, 오버레이/행동감독/소스 다양성/대안 로봇화 방식까지 통제 실험이 촘촘하다.
- 동일 파이프라인이 다른 로봇으로 저비용 확장되고 교차 체화 전이도 확인.

**한계**
- 모든 평가가 실로봇 소수 과제(롤아웃 10~24회)이며 공개 시뮬레이션 벤치마크 결과가 없다.
- 로봇 오버레이가 장면과의 가림(occlusion)을 모델링하지 않고, 자기충돌·접촉·힘 정보가 없다(자기접촉 없음 55.2%). 저자들도 "실행 가능한 시연"이 아니라 사전학습 감독이라고 명시.
- 파이프라인이 다수의 외부 모델(HaWoR, DROID-SLAM, SAM2, ProPainter, Isaac Sim, Qwen3.5)에 의존해 재현 비용이 크다.

## 12. VLA-Tracker 관점 평가
HuRo는 데이터셋 논문 성격이 강하지만, 해당 데이터로 GR00T-N1.6 구조 VLA를 직접 사전학습(액션 헤드는 처음부터 학습)하고 미세조정해 정량 결과를 보고하므로 규칙상 자체 학습 정책으로 ACCEPTED. 액션 헤드는 DiT flow matching이므로 `action_head_category: flow_matching`. 추적 벤치마크(LIBERO 등) 결과는 없고, ALLEX 4과제 헤드라인(ID 88.4 / OOD 72.2 / 전체 80.3)을 `real_world`에, 과제별·기준선·스케일링·어블레이션·OpenArm 전이는 별도 블록으로 분리했다. 비디오 생성 비교(Fig. 6)와 Visual-Only 수치는 그림에만 있어 기록하지 않았다.
