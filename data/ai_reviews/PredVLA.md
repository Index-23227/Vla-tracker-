# PredVLA — Predictive Sensorimotor Modeling for Sub-Million-Parameter Robot Manipulation

- arXiv: 2608.26673 (v1 2026-08-27, v2 2026-08-30; arXiv 목록 제목 "A Sub-Million-Parameter Predictive-Coding Policy for Robot Manipulation")
- 소속: Sony Computer Science Laboratories, 도쿄 (Hiroki Sawada, Shunichi Kasahara)

## 1. 한 줄 요약

PredVLA는 학습 가능한 파라미터가 **0.68M(675,732개)**뿐이고 로봇 데이터 사전학습이 없는 언어 조건 predictive-coding 정책이다. 관측을 순환망에 직접 넣지 않고, 순환 생성모델이 시각 특징과 고유수용감각을 예측한 뒤 **예측 오차를 줄이도록 잠재 변수를 온라인 최적화(error regression)**해 행동을 만든다. LIBERO 3-suite 평균 86.94%, 4-suite 평균 75.35%로, 같은 조건의 파라미터 매칭 Transformer/LSTM BC 대비 3-suite 기준 3.7배/7.4배다.

## 2. 문제 설정

최고 성능 VLA는 수십억 파라미터이고, TinyVLA·SmolVLA·Evo-1 같은 경량 모델도 수억 규모로, 대부분 기존 관측→행동 매핑을 압축하는 방향이다. 저자들은 "작은 예산에서는 다른 학습 원리가 파라미터를 더 잘 활용할 수 있는가"를 묻고, 그 후보로 예측(predictive coding)을 귀납 편향으로 검증한다.

## 3. 핵심 아이디어

PV-RNN 계열 predictive-coding 순환망을 현대 VLA 평가 체계(LIBERO)에 가져온다. 관측은 자유 에너지 목적함수에만 등장하며, 순환 상태에는 예측 오차를 역전파한 잠재 자유변수 갱신을 통해서만 영향을 준다. 따라서 추론 반복을 0으로 두면 같은 모델·같은 언어 조건으로 **정확한 open-loop 대조군**을 얻을 수 있다.

## 4. 아키텍처

고정 전단: all-MiniLM-L6-v2 문장 임베딩(384→PCA 64), 카메라별 ImageNet ResNet18(512→PCA 96, agentview + eye-in-hand, 4 제어 스텝마다 갱신), 9차원 고유수용감각. 학습 가능 부분은 상위 모듈 T(64), 시각 모듈 V(256), 행동 모듈 A_top(256)·A_bottom(256)의 계층형 다중 시간척도 RNN이다. 시간상수 τ는 단기 과제 (16,8,5,2), LONG은 (30,14,8,2). 각 모듈은 부모 출력에서 생성되는 prior와 추론되는 posterior 자유변수(64차원)를 가진다. 언어는 T에만 가산 입력된다. V→A_top 저차원 병목(256→32→256)과, 모델 자신의 이전 행동·고유감각 예측을 V로 되돌리는 efference copy 경로가 있다(실측값이 아님). 출력은 MLP로 시각 예측, 고유감각 예측, 5성분 가우시안 혼합 행동 분포이며 최대 가중치 성분의 평균을 실행한다.

## 5. 학습과 추론

학습 손실은 시각 예측 오차 + 고유감각 예측 오차 + 행동 NLL + 복잡도(posterior와 prior의 가중 제곱 거리)이며, 시연·시점마다의 posterior 자유변수를 네트워크 가중치와 함께 BPTT로 최적화한다. suite별로 처음부터 학습(30K 스텝, 배치 32, Adam, 네트워크 LR 6e-5, posterior LR 1e-2, 시퀀스 200/500). 추론 시 가중치는 고정하고 최근 40스텝 창에서 posterior만 Adam 10회(스텝 0.05)로 갱신한 뒤 A_bottom에서 행동을 디코딩한다. RTX 5090에서 전단과 error regression을 포함해 스텝당 46 ms(21.6 Hz).

## 8. 메커니즘 사다리 (Table 5, 3-suite 평균, 7 시드)

L0 PredVLA 86.09 → L1 온라인 error regression 제거 77.26(−8.83) → L2 자유변수·잠재 추론 제거 63.92(−13.34) → **L3 예측 경로 제거(관측 직접 입력) 11.56(−52.36)** → L4 τ=1 10.33 → L5 LSTM 셀 14.52 → L6 기존 BC-RNN 11.68. L2→L3 단계가 전체 74.41pt 격차의 70.4%를 차지한다. 곁가지 L2b(L2 + 행동 경로에 직접 시각 입력, 파라미터 7.3% 증가)는 오히려 48.60으로 떨어져, 단순히 시각 정보 접근이 부족해서가 아니라는 점을 보인다.

## 10. 강점

- 파라미터를 엄격히 매칭한 통제 비교와 단계별 사다리로 "예측 구조 자체"의 기여를 정량적으로 분리했다.
- 14 시드·과제당 50 롤아웃(suite당 7,000 에피소드)으로 통계적 신뢰도가 높고, 표준편차를 보고한다.
- 구조적으로 정확한 open-loop 대조군을 얻을 수 있는 해석 가능성.
- 사전학습 없이 0.68M 파라미터로 LIBERO 4-suite 75%대를 달성한 흥미로운 효율 지점.

## 11. 한계

- suite마다 별도 모델을 학습하는 단일-suite 설정이라, 다중 과제 일반 정책인 대형 VLA와 직접 비교하기 어렵다.
- LONG 40.57%로 장기 과제 성능이 크게 떨어진다.
- 시뮬레이션(LIBERO)만 평가했고 실로봇 결과가 없으며 코드 공개 언급이 없다.
- 결과가 고유감각 신호에 크게 의존해(특히 Object), 시각 교란보다는 고유감각 오류에 취약하다.
- 베이스라인이 모두 같은 약한 고정 전단(ResNet18+PCA)에 묶여 있어, 전단을 강화했을 때도 격차가 유지되는지는 미지수다.

## 12. VLA-Tracker 관점 평가

고정 인코더 위에서 0.68M 파라미터 predictive-coding 컨트롤러를 처음부터 학습한 자체 정책이므로 수록 대상이다. 트래커에는 4 suite 점수와 논문이 보고한 4-suite 평균(libero_avg 75.35) 및 3-suite 평균(86.94)을 기록하고, 통제 베이스라인·어블레이션·사다리를 별도 블록으로 두었다. LIBERO 순위표에서는 하위권이지만, "초소형·무사전학습" 축의 기준점이자 predictive coding/free-energy 계열 정책의 드문 표준 벤치마크 사례로 가치가 있다. suite별 개별 학습이라는 점을 순위 비교 시 반드시 감안해야 한다.
