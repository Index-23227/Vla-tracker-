# ViTaR — Visuo-Tactile Residual Adaptation for Foundation VLA Manipulation

**arXiv**: 2608.15816 · **기관**: Beijing Institute of Technology · **날짜**: 2026-08-16

## 1. 한 줄 요약
촉각을 행동을 생성하는 입력이 아니라 "실행 조절자(execution modulator)"로 재정의하여, 동결된 OpenVLA-OFT 위에 촉각 증거로 선택·스케일되는 유계(bounded) 잔차 보정을 학습함으로써 UniVTAC 7개 접촉 과제 평균 61.3%(베이스 대비 +30.6 pp)를 달성한 방법.

## 2. 문제 설정
- VLA는 넓은 시각-의미 사전지식을 갖지만 국소 접촉 사건을 보지 못해, 접촉이 성립·상실·불안정한 상황에서도 같은 행동을 낸다.
- 기존 해법: (a) 촉각을 VLA 내부에 융합 → 재앙적 망각 위험, (b) 온라인 RL 적응 → 파손 직전 접촉 상태에서 탐색 필요. 둘 다 촉각에 행동 생성에 대한 무제한 영향력을 준다.
- 관찰: 동결 VLA는 의미적으로 올바른 행동 "방향"을 이미 제공하며, 부족한 것은 접촉 조건에서의 실행 "보정"이다.

## 3. 핵심 아이디어
- 실행 행동 A_exec = A_ref + ΔA. ΔA는 0(베이스 유지)이거나, 동결 VLA 액션 청크의 주요 부호 성분에서 도출한 작은 7D 델타 후보 집합 R 중 하나에 스케일 α를 곱해 청크 전체에 균일 적용.
- 두 단계: **EGM(Effect-Guided Modeling)**이 "개선 가능한 상태인가"와 "어떤 잔차가 국소적으로 더 나은가"를 상태 내 선호 비교로 학습하고, **RAM(Residual Action Modulation)**이 이를 실제 배포용 이산 선택 + 촉각 조건 연속 게인으로 변환.

## 4. 아키텍처
- 베이스: OpenVLA-OFT, 저자가 UniVTAC 과제당 50개 궤적(총 350)으로 OFT 파인튜닝한 뒤 동결.
- 상태 표현 x_i: 마커 변위 기반 접촉 기술자 m_i, 시각-고유수용 관측, 언어 임베딩, 실행 이력, 베이스 액션 인코딩.
- EGM: 2층 선형+ReLU 상태 인코더, 1층 후보 인코더, 효과 헤드(선형–ReLU–선형), 별도 적응성 게이트 헤드. 은닉 폭 128.
- RAM: 3층 MLP 선택기(폭 128, 출력 차원 = 베이스 + 잔차 옵션 수), 동일 패턴의 크기 모델(입력 x_i, 선택된 잔차, 양측 촉각 요약 z_i → sigmoid 게인).
- z_i는 게인 α만 조절하며 베이스 행동·잔차 방향·후보 집합은 바꿀 수 없음. 10 Hz 제어 주기.

## 5. EGM 학습
- 복원된 공통 결정 지점에서 각 행동 선택으로 짧은 분기 롤아웃 실행 → 과제 결과·마커 기반 접촉 유지·복원 품질로 국소 점수 q_i(c) 계산.
- Δq = q(u) − q(∅)와 δ=0.05로 잔차를 양성/중립/음성으로 분할, "양성 ≻ 베이스 ≻ 음성", "양성 ≻ 중립" 선호 생성.
- 점수 격차와 복원 신뢰도(복원 검사 실패 시 κ=0.25)로 가중한 Bradley–Terry 손실 + 적응성 BCE (λ_adapt=1). AdamW, lr 1e-3, 120 epoch. 학습 후 동결.

## 6. RAM 학습
- 선택기 라벨: 양성 잔차가 없으면 베이스, 있으면 Δq가 가장 큰 잔차. 베이스도 일반 클래스로 취급(사후 폴백 게이트가 아님). 교차 엔트로피 + 잔차 질량 정규화.
- 게인 목표: 단일 진폭으로 수집된 분기 데이터라 물리적 정답 스케일이 없으므로 EGM 순위를 보조 게인 목표로 사용(가중 BCE). 보충 실험에서 240개 hold-out 상태 × 4개 스케일 × 3회 반복으로 배포 스케일을 직접 검증.
- 데이터: 과제당 20개 복원 그룹, 그룹당 5개 분기 → 과제당 100 롤아웃, 160 쌍. RTX 4090 8장.

## 8. 실제 로봇 결과
RealMan RM-65B(6-DoF) + DH 모터 기반 맞춤 촉각 그리퍼 + 9DTact 센서, 과제당 20회. 본문 수치: Insert Hole 40.0%, Wiping the Board 40.0%, Lift Bottle 65.0%, 평균 48.3%. 평균 기준 OpenVLA-OFT 대비 +30.0 pp, Tactile-VLA 대비 +15.0 pp, ACT 대비 +21.7 pp. (기준선의 과제별 막대 값은 그림에만 있어 YAML에는 기록하지 않았다.)

## 10. 강점
- 촉각 영향력을 게인으로만 제한하는 설계로 사전학습 표현을 구조적으로 보존하면서 안전성 지표(unsafe 0.04)도 개선.
- 전역 보상 대신 동일 상태 내 분기 비교라는 국소 선호 신호로, 이질적인 접촉 상태 간 보정 문제를 회피.
- 적은 추가 데이터(과제당 20개 복원 그룹)로 베이스 성능을 두 배로 끌어올림.

## 11. 한계
- 성능 상한이 동결 베이스의 의미적 행동 품질에 묶임(저자 명시). 잔차 방향은 소수의 고정 후보에 한정.
- 분기 데이터 수집에 상태 복원이 필요해 실제 환경에서는 비용과 근사 오차가 큼.
- 실제 로봇 실험은 3과제 × 20회로 제한적이며, 다수 최신 촉각 VLA(TacCoRL, TORL-VLA 등)는 재현 불가로 비교에서 제외.
- 게인 목표가 물리적 크기가 아닌 순위 대리값.

## 12. VLA-Tracker 관점 평가
경계 사례. 베이스 VLA는 추론 시 동결이지만, (1) 저자가 OpenVLA-OFT를 UniVTAC 시연으로 직접 파인튜닝했고, (2) 실제 실행 행동의 일부(잔차 방향 선택과 크기)를 출력하는 EGM/RAM 네트워크를 가중치 학습으로 얻는 학습형 잔차 정책이다. 가중치 갱신 없는 조향·게이트 레이어가 아니라는 점에서 ACCEPTED로 판단했다. 최종 행동은 회귀형 OFT 청크 + MLP 잔차이므로 `action_head_category: regression`. UniVTAC 본 결과는 `univtac` 블록, 기준선·어블레이션·실제 로봇 결과는 별도 블록에 등록했다. 추적 대상 표준 벤치마크 평균은 없다.
