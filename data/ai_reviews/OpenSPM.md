# OpenSPM: An Environment-Transferable Robotic Key Spatial Pose Memory and Closed-Loop High-Frequency Flow-Matching Action Generation Model

> **한 줄 요약**: end-to-end VLA 대신 **분해적(decompositional) 접근** — SAM 3/SAM 3D + Kalman 필터로 6D 포즈를 추정하고, 데모를 object-centric SE(3) 상대 포즈의 "key spatial pose memory bank"로 압축한 뒤, **240K 파라미터**짜리 조건부 flow-matching 모델로 키포즈 사이 action chunk(H=5)를 생성. LIBERO-GOAL 10 태스크에서 **85.6%** 성공률, 4.8 ms 지연으로 **등가 1033.3 Hz** 제어 주파수 달성. Closed-loop 보정 제거 시 3.0%로 붕괴 — 폐루프가 성능의 사실상 전부.

---

## 1. 배경 및 동기

- 오픈 환경 탁상 조작(tabletop manipulation)은 (1) 의미 이해, (2) 정밀한 기하학적 포즈 추정, (3) 고주파 액션 생성을 동시에 요구
- 기존 end-to-end VLA(RT-1/RT-2, OpenVLA, Octo, π0 등)는 의미적 일반화에 강하지만:
  - 대규모 로봇 데이터와 고비용 학습 필요
  - 액션 출력에 **명시적 object-centric 기하 제약이 없음** → 접촉 민감 단계(파지, 배치)에서 불안정
  - few-shot·저연산·고주파 제어 환경에서 배포 곤란
- 본 논문의 관점: 상위 모델은 의미 파싱·경험 검색, 하위 모델은 기하 제약된 국소 액션 생성을 담당하는 **분해적 설계**. 중간 표현으로 **key spatial pose**(조작 단계 경계를 표시하는 end-effector-대-객체 상대 포즈) 사용

## 2. 방법론 심층 분석

### 2.1 의미 조건부 3D 인식 + Kalman 상태 추정 (§3.2)
- 세그멘테이션(SAM 3 계열) → 3D 재구성(SAM 3D) → 상태 일관 추정의 캐스케이드 구조
- 멀티뷰: 알려진 내·외부 파라미터로 2D 마스크를 월드 좌표 점 집합 제약으로 리프팅; 단일 뷰: 객체 수준 3D 재구성으로 국소 형상·주축 방향 획득
- 포즈 추정을 노이즈 상태공간 문제로 취급: 상태 벡터 $x_t = [p_t, \dot{p}_t, \theta_t, \omega_t]$, 표준 Kalman predict/update (식 6–9) + slerp 기반 경량 스무딩 (식 10)
- 관측 공분산 $R_t$는 세그멘테이션 신뢰도·마스크 면적·멀티뷰 일관성·3D 재구성 품질로 결정
- 핵심: 매 프레임 고비용 3D 재구성을 하지 않고, 데모 구축·에피소드 초기화 시에만 수행 후 저차원 필터링으로 연속성 유지

### 2.2 Key Spatial Pose Memory Bank (§3.3)
- 키포즈 후보는 3가지 증거로 결정: 그리퍼 상태 전이, end-effector 속도/방향 변화, **Qwen3-VL의 phase-semantic 판단**(3뷰 이미지 + 궤적 JSON)
- 메모리 엔트리 (식 11): 검색 키 $k_i$(조작 유형·대상·배치 객체·단계 구조), 언어 설명 $l_i$, **객체 좌표계 상대 포즈** $\Delta T^{o\to e}_{i,j}$, 단계 라벨, 신뢰도, 품질 점수·버전
- 전이 가능성의 핵심 = 월드 절대 포즈가 아닌 상대 포즈 저장: $\Delta T^{o\to e}_j = {}^wT_o^{-1}\,{}^wT_{e,j}$ (식 12)
- 온라인 검색 (식 13): 의미 매칭 $S_{sem}$ + 기하 사용성 $S_{geo}$ + 이력 품질 $r_i$의 가중합 argmax

### 2.3 상대 포즈 전이 (§3.4, Theorem 1)
- 새 장면에서 ${}^wT'_{e,j} = {}^wT'_o \Delta T^{o\to e}_j$ (식 14)
- **Theorem 1**: 객체 포즈가 임의 강체변환 $G \in SE(3)$만큼 달라져도 상대 포즈 전이 규칙 하에서 end-effector-객체 국소 기하는 불변 (SE(3) 결합법칙으로 증명)
- 파지 단계는 파지 객체, 배치 단계는 배치 대상을 anchor로; 서랍/손잡이류는 관절축 방향 포함. 전이 후 도달성·포즈 점프·최소거리 검사

### 2.4 조건부 Flow-Matching 액션 생성 (§3.5)
- 조건 $c_t = \phi({}^wT_{e,t}, {}^wT_{e,j}, {}^wT_{e,t}^{-1}{}^wT_{e,j}, \tau)$ — 현재 포즈, 목표 키포즈, 상대 오차, 세그먼트 진행도
- 액션 $a_t = (\Delta p_t, \Delta\omega_t, g_t) \in \mathbb{R}^7$, chunk 길이 H=5
- 표준 선형 보간 경로 + MSE velocity 학습 (식 19–21), 추론은 ODE 적분 (식 22)
- 조건 인코더 1회 인코딩 → step-wise decoder가 ODE 스텝마다 재사용 (전역 조건 반복 인코딩 회피)
- **약 240K 파라미터** — 이미지/언어 토큰을 전혀 처리하지 않는 저차원 MLP

### 2.5 폐루프 실행 + 터미널 잔차 보정 (§3.6)
- 세그먼트 간 폐루프: 각 chunk 시작 시 **실시간 그리퍼 포즈**를 조건으로 사용 (계획상 이상 시작점 아님)
- 터미널 잔차 보정(TRC): 파지·배치 노드 근처에서 $\|r_t\|_2 > \epsilon_r$이면 현재 실제 상태로 조건 재구성 → 보정 chunk 생성, 오차 수렴 또는 최대 반복까지
- 오차 전파 분석 (§3.7): 개루프 $e_{m+1} = A_m e_m + \delta_m + \eta_m$을 관측 보정 $B_m$으로 대체, TRC가 접촉 노드 근처에서 반복적 수축

> ❓ **예상 질문**: 이게 VLA인가?
> **답변**: end-to-end VLA는 아니다. 언어→액션 매핑이 "검색+기하 전이+국소 생성"으로 분해된 모듈형 정책. 다만 언어 조건부로 액션을 생성하는 policy이며 VLA 베이스라인과 동일 벤치마크에서 직접 비교되므로 VLA 트래킹 범주에 포함 가능. 저자들 스스로 "end-to-end VLA의 보완재"로 포지셔닝.

## 3. 실험 설정

- **LIBERO-GOAL 10개 언어 조건 태스크**, 태스크당 50개 초기 상태 = 총 500 에피소드
- 지표: 성공률, 단일 chunk 생성 지연, 등가 액션 출력 주파수 $f = 1000H/t$ Hz (식 27), 평균 실행 스텝
- 모듈 수준 실험 3종: Kalman 포즈 예측 평가, 메모리 뱅크 ablation, 폐루프+TRC ablation
- 주의: 실패 에피소드 내 물리 실패/충돌률은 전체 충돌률과 다름 (실패 샘플 내 파괴적 상호작용 비율)

## 4. 핵심 결과 (Table 1)

| Method | Paradigm | Params | Chunk | SR / Freq |
|---|---|---|---|---|
| Diffusion Policy | Diffusion | ~260M | 8 | 68.3% / 14.2 Hz |
| TraceVLA | VLA | 7B | 1 | 75.1% / 2.2 Hz |
| SpatialVLA | VLA | 4B | 4 | 78.6% / 6.7 Hz |
| OpenVLA | VLA | 7B | 1 | 79.2% / 4.9 Hz |
| WorldVLA | WAM | 7B | 25 | 83.4% / 2.4 Hz |
| Octo-Base | Diffusion | ~200M | 4 | 84.6% / 54.7 Hz |
| **OpenSPM (Ours)** | **Flow matching** | **0.24M** | **5** | **85.6% / 1033.3 Hz** |

- 7B VLA 대비 **~30,000배 작은 액션 모델**로 LIBERO-GOAL SOTA급 성공률, 추론 지연 4.8 ms
- Kalman 포즈 예측 (Table 2): 10 태스크 평균 위치 MAE **5.8 mm**(최대 14.7), 방향 MAE **2.12°**(최대 6.4) — frame-by-frame SAM 3 + SAM 3D 참조 대비

## 5. Ablation — 메모리 뱅크 (Table 3)

| 설정 | SR |
|---|---|
| Zero-shot 멀티모달 키포즈 추론 (메모리 제거) | 23.8% |
| OpenSPM full | **85.6%** |

- 메모리 뱅크는 단순 캐시가 아니라 **물리적으로 실행 가능한 prior**: 접촉점·접근 방향·해제 위치·단계 경계의 암묵지를 객체 좌표계에 명시적으로 인코딩. 멀티모달 모델이 연속 3D 공간에서 상호작용 지점을 zero-shot으로 추측하는 것은 신뢰 불가 (–61.8%p)

## 6. Ablation — 실행 전략 + TRC (Table 4)

| 설정 | SR | ΔSR | 평균 스텝 |
|---|---|---|---|
| 개루프 flow matching | 3.0% | –82.6 | 173.2 |
| 세그먼트 간 폐루프 | 29.8% | –55.8 | 166.6 |
| 폐루프 + TRC | **85.6%** | 0 | 278.5 |

- **가장 중요한 표**: 순수 flow-matching 생성 자체는 개루프로는 3.0% — 다중 세그먼트 연결에서 오차가 급속 누적
- TRC가 성공률을 29.8→85.6%로 끌어올리지만 평균 스텝을 167→278.5로 증가시킴 (임계 접촉 노드 근처 반복 정렬 비용; 연산 병목이 아니라 환경 실행 스텝 비용)

## 7. 수렴·오차·실패 모드 분석 (§4.7)

- Flow-matching 모델은 ~200 epoch 내 수렴, validation rebound 없음 — 저차원 입력(포즈·오차·진행도)으로 가설 공간이 end-to-end VLA보다 훨씬 작기 때문
- Validation 액션 오차 ≠ 태스크 성공률: cm급 단일 스텝 오차도 파지·삽입·서랍 접촉에서는 허용 여유를 초과 가능
- 실패 3범주: (1) 상류 2D 세그멘테이션 오류가 3D 앵커 이탈로 전파 (유사·가림 심한 둥근 객체), (2) 가늘거나 지지 영역 좁은 객체의 작은 허용 오차, (3) 환경 기하 제약 (경로 차단, 서랍 경계–그리퍼 충돌) — TRC로 극복 불가

## 8. 강점

- **극단적 효율**: 0.24M 파라미터, 4.8 ms, 1033.3 Hz — 저연산 실기 배포에 매력적
- SE(3) 상대 포즈 전이의 **형식적 일관성 보장** (Theorem 1) — 해석 가능하고 검증 가능한 전이
- Ablation이 체계적: 메모리·폐루프·TRC 각각의 기여를 분리 정량화
- Few-shot: 대규모 로봇 데이터 사전학습 불필요, 데모에서 직접 메모리 구축

## 9. 약점 / 한계

- **LIBERO-GOAL 단일 스위트만 평가** — SPATIAL/OBJECT/LONG 및 타 벤치마크 부재, LIBERO 4-suite 평균 산출 불가
- **실기(real-world) 실험 전무** — 전부 시뮬레이션; Kalman·SAM 파이프라인의 실기 강인성 미검증
- 등가 주파수 1033.3 Hz는 액션 모델만의 수치 — SAM 3/SAM 3D/Qwen3-VL 인식 비용은 초기화로 분리 계상되어 있어 총 시스템 지연과 다름 (공정성 논쟁 여지)
- 멀티뷰 카메라 내·외부 파라미터 필요 — "open environment" 주장 대비 셋업 요구가 큼
- 메모리 검색이 데모된 조작 유형에 한정 — 진짜 novel 조작에는 일반화 불가 (검색 기반의 근본 한계)
- 코드 공개 여부 언급 없음 (이름의 "Open"은 open-environment 의미)

## 10. 다른 연구와의 위치

- vs. **end-to-end VLA** (OpenVLA, π0, SpatialVLA): 의미 일반화는 VLM에 위임하되 액션 생성을 기하 구조로 대체 — 상보적 관계로 포지셔닝
- vs. **Diffusion Policy / Octo**: 동일하게 생성 모델이지만 이미지 조건 대신 저차원 포즈 조건 → 파라미터 3자릿수 절감
- vs. **keyframe 기반** (Perceiver-Actor 등): 키포즈를 world 좌표가 아닌 object-centric SE(3) 상대 포즈로 저장해 장면 간 전이 확보
- vs. **retrieval 기반 로봇 시스템**: 궤적 재생이 아닌 단계 라벨 상대 포즈 → 의미 검색·기하 전이·실행 검증 가능

## 11. 향후 연구 방향

- 저자 제안: 메모리 엔트리에 그리퍼 폭·접촉 이벤트·국소 법선·장애물 거리·힘 관련 제약 추가
- 자연 확장: LIBERO 전체 4-suite 및 실기 검증, 대규모 메모리 뱅크의 벡터 인덱싱(§3.7 언급), 장애물 회피 통합 (실패 모드 3 대응)

## 12. 종합 평가

분해적·기하 중심 접근이 특정 조건(few-shot, 저연산, 고주파)에서 대형 VLA를 능가할 수 있음을 깔끔하게 보여준 논문. Theorem 1의 SE(3) 전이 일관성과 3단계 ablation(3.0→29.8→85.6%)이 설계 논리를 잘 뒷받침한다. 다만 LIBERO-GOAL 단일 스위트·시뮬레이션 한정 평가, 인식 비용을 제외한 주파수 산정은 주장 대비 증거가 얇은 부분. "VLA의 대체"라기보다 정밀 접촉 단계를 위한 기하 메모리 모듈로서의 가치가 크며, VLA와의 하이브리드가 자연스러운 다음 단계다.
